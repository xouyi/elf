# Registry

Prefer to own the code? The [shadcn-vue](https://www.shadcn-vue.com) CLI can copy Elf components into your
project so you can fork them freely. Imports are rewritten to your own aliases (`@/lib/utils`,
`@/components/ui/*`).

## Add a single component

```bash
bunx shadcn-vue@latest add https://xouyi.github.io/elf/r/button.json
```

Dependencies such as `utils` are installed automatically through `registryDependencies`.

## Register the namespace

Add this to your `components.json`, then use short names:

```json
{
  "registries": {
    "@elf": "https://xouyi.github.io/elf/r/{name}.json"
  }
}
```

```bash
bunx shadcn-vue@latest add @elf/button @elf/dialog @elf/elf-theme
```

## Available items

| Item | Description |
| :-- | :-- |
| `utils` | `cn()` helper (clsx and tailwind-merge) |
| `button`, `input`, `badge`, `card`, `dialog`, `tabs` | Components |
| `elf-theme` | Tailwind v4 token mapping and the `elf` and `novatron` theme files |

## Fallback host

If GitHub Pages is unavailable, the same files are served from the repository:

```text
https://raw.githubusercontent.com/xouyi/elf/main/registry/r/{name}.json
```

Note that items fetched from the fallback still list the Pages URL in their `registryDependencies`.

## Package or registry?

| | Package (`@elf/ui`) | Registry |
| :-- | :-- | :-- |
| Updates | Bump the tag | Re-run `add` and merge |
| Customization | Props, classes, tokens | Edit the source |
| Best for | Following the design system | Heavily customized apps |
