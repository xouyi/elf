# Theming

A theme is a set of CSS variables prefixed with `--elf-`, declared under `[data-theme='<name>']`. Components never
hard-code colors: they use Tailwind utilities (`bg-primary`, `border-border`) that resolve to these variables.

## Themes

| Theme | Character | Radius | Primary |
| :-- | :-- | :-- | :-- |
| `elf` (default) | Near-black surfaces with violet accents | `0.625rem` rounded | violet |
| `novatron` | Obsidian black with gold, built for Novatron Robotics apps | `0` sharp corners | gold `#ffcc00` |

Elf is **dark only**. There is no light theme and `color-scheme` is always `dark`. Do not add light variants.

## Switching themes

```ts
document.documentElement.dataset.theme = 'elf' // or 'novatron'
```

With the Nuxt module the initial theme is the `elf.theme` option. Bundle every theme you switch to with
`elf.themes`. Tokens can also be scoped to any element:

```html
<section data-theme="elf">This subtree uses the elf theme.</section>
```

## Token reference

| Token | Tailwind utility | Purpose |
| :-- | :-- | :-- |
| `--elf-background` / `-foreground` | `bg-background` `text-foreground` | Page surface and default text |
| `--elf-card` / `-card-foreground` | `bg-card` | Cards and panels |
| `--elf-popover` / `-popover-foreground` | `bg-popover` | Dialogs and floating surfaces |
| `--elf-primary` / `-primary-foreground` | `bg-primary` | Main actions and emphasis |
| `--elf-secondary` / `-secondary-foreground` | `bg-secondary` | Secondary actions |
| `--elf-muted` / `-muted-foreground` | `bg-muted` `text-muted-foreground` | Subtle surfaces, helper text |
| `--elf-accent` / `-accent-foreground` | `bg-accent` | Hover and selected states |
| `--elf-destructive` / `-destructive-foreground` | `bg-destructive` | Dangerous actions and errors |
| `--elf-success` / `-success-foreground` | `bg-success` | Positive status |
| `--elf-warning` / `-warning-foreground` | `bg-warning` | Cautionary status |
| `--elf-border` | `border-border` | Borders and dividers |
| `--elf-input` | `border-input` | Form control borders (3:1 contrast) |
| `--elf-ring` | `ring-ring` | Focus ring (3:1 contrast) |
| `--elf-radius` | `rounded-lg` and friends | Base corner radius |
| `--elf-radius-pill` | `rounded-badge` | Badge radius |

## Creating a theme

1. Create `src/themes/<name>.css` in the repo (or any CSS file in your app) and define every token:

   ```css
   [data-theme='ocean'] {
     --elf-background: oklch(0.14 0.02 240);
     --elf-foreground: oklch(0.97 0.005 240);
     /* ...every token from the table above, with -foreground pairs... */
     --elf-radius: 0.5rem;
     --elf-radius-pill: 9999px;
   }
   ```

2. Import it after `@import '@elf/ui/styles.css'`.
3. Set `data-theme="ocean"`.
4. In this repository, add the name to `elfThemes` in `src/index.ts`, and run `bun run contrast` to verify
   WCAG AA: 4.5:1 for text pairs and 3:1 for the input border and focus ring.

## Elf vs Novatron

Use **elf** for general products. Use **novatron** for anything representing Novatron Robotics (FRC Team 10202):
obsidian `#050505` background, gold `#ffcc00` primary, and `0` radius everywhere. Under novatron, rounded utilities
such as `rounded-md` resolve to `0` because they derive from `--elf-radius`, so never override radii with
arbitrary values.
