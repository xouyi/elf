# Using without Nuxt

Elf works in any Vue 3 app built with Vite. The Nuxt module only automates component registration, theme CSS and
the `data-theme` attribute, so you do those three things yourself.

## 1. Install

```bash
bun add github:xouyi/elf#v0.2.0 vue tailwindcss @tailwindcss/vite
bun add -d typescript vite @vitejs/plugin-vue
```

## 2. Vite config

```ts
// vite.config.ts
import tailwindcss from '@tailwindcss/vite'
import vue from '@vitejs/plugin-vue'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [vue(), tailwindcss()],
})
```

Elf ships `.vue` and `.ts` sources. Vite compiles them like your own code, so no extra transpile step is needed.

## 3. Styles and theme

```css
/* src/style.css */
@import 'tailwindcss';
@import '@elf/ui/styles.css';
@import '@elf/ui/themes/elf.css';
@import '@elf/ui/themes/novatron.css';
```

```html
<!-- index.html -->
<html lang="en" data-theme="elf">
```

## 4. Import components

```vue
<script setup lang="ts">
import { ElfButton, ElfCard, ElfCardContent } from '@elf/ui'
</script>

<template>
  <ElfCard>
    <ElfCardContent><ElfButton>Save</ElfButton></ElfCardContent>
  </ElfCard>
</template>
```

Types are exported too: `ButtonProps`, `BadgeProps`, `ButtonVariants`, `BadgeVariants`, and the helpers `cn`,
`buttonVariants`, `badgeVariants`, `elfThemes`, `ElfTheme`.

## Switching themes

```ts
document.documentElement.dataset.theme = 'novatron'
```

Tokens are scoped to `[data-theme]`, so a single element can use a different theme from the page:
`<div data-theme="elf">...</div>`.
