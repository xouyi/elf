# Components

Every Vue component has the `Elf` prefix. In Nuxt they are auto-imported; elsewhere import them from `@elf/ui`.

| Component | Parts | Use it for |
| :-- | :-- | :-- |
| [Button](?path=/docs/components-button--docs) | `ElfButton` | Actions. Six variants, four sizes, renders any element with `as-child`. |
| [Input](?path=/docs/components-input--docs) | `ElfInput` | Single-line text entry with `v-model`. |
| [Badge](?path=/docs/components-badge--docs) | `ElfBadge` | Status and labels. Six variants. |
| [Card](?path=/docs/components-card--docs) | `ElfCard`, `ElfCardHeader`, `ElfCardTitle`, `ElfCardDescription`, `ElfCardAction`, `ElfCardContent`, `ElfCardFooter` | Grouped content. |
| [Dialog](?path=/docs/components-dialog--docs) | `ElfDialog`, `ElfDialogTrigger`, `ElfDialogContent`, `ElfDialogHeader`, `ElfDialogTitle`, `ElfDialogDescription`, `ElfDialogFooter`, `ElfDialogClose`, `ElfDialogOverlay` | Modal interactions and confirmations. |
| [Tabs](?path=/docs/components-tabs--docs) | `ElfTabs`, `ElfTabsList`, `ElfTabsTrigger`, `ElfTabsContent` | Switching between related views. |

Each component page contains usage, a props table, a variants gallery, accessibility notes and do and don't guidance.
Every story is rendered in both themes in the **Both themes** story.
