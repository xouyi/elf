## Usage

```vue
<ElfSkeleton class="h-4 w-40" />
<ElfSkeleton class="size-10 rounded-full" />
```

Reka UI has no skeleton, so `ElfSkeleton` is a composed `div`. It only takes `class`: set its size and shape there so the placeholder matches the content that replaces it.

## Accessibility

- Every skeleton is `aria-hidden="true"`: it carries no information.
- Mark the region that is loading with `aria-busy="true"` and render a visually hidden `role="status"` message (an `aria-label` is only valid on elements with a role, such as a list), so users of assistive technology know content is coming.
- The pulse animation stops under `prefers-reduced-motion: reduce`.
- Skeletons are not focusable and have no keyboard interaction.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Match the size and shape of the final content. | Use identical blocks for unrelated content. |
| Announce the loading state on the container. | Rely on the animation to communicate loading. |
| Use a [Spinner](/docs/components/spinner) for short waits with no known layout. | Show skeletons for more than a few seconds without an error path. |
