## Usage

```vue
<ElfKbd>Esc</ElfKbd>

<ElfKbdGroup>
  <ElfKbd>Ctrl</ElfKbd>
  <span aria-hidden="true">+</span>
  <ElfKbd>K</ElfKbd>
</ElfKbdGroup>
```

Reka UI has no keyboard-hint primitive, so `ElfKbd` is composed from the native `kbd` element and Reka's `Primitive` (for `as` and `as-child`).

## Accessibility

- The `kbd` element marks text the user types. Screen readers read its content as text, so write key names ("Ctrl", "Enter") rather than symbols that are read poorly.
- Icon-only keys must contain visually hidden text naming the key, and the icon itself should be `aria-hidden`.
- A hint is not a control. Always make the shortcut's action reachable by a visible control as well, and register the real shortcut in your app code.
- The key caps are not interactive (`pointer-events: none`, `select-none`) and are not focusable.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Name keys in words (`Ctrl`, `Shift`). | Use symbols screen readers cannot pronounce without a label. |
| Use `ElfKbdGroup` for combinations. | Put a `+` between keys inside the same `ElfKbd`. |
| Show the shortcut next to the action it triggers. | Rely on a shortcut as the only way to act. |
