## Usage

```vue
<ElfSeparator class="my-4" />
<div class="flex h-5 items-center gap-4">
  <span>Docs</span>
  <ElfSeparator orientation="vertical" />
  <span>Examples</span>
</div>
```

`decorative` defaults to `true` (a deliberate difference from Reka UI, matching shadcn-vue), because most dividers are visual only.

## Accessibility

- Decorative (default): the element gets `role="none"` and is ignored by assistive technology.
- `:decorative="false"`: `role="separator"` is exposed; vertical separators also set `aria-orientation="vertical"` (horizontal is the implicit default).
- The separator is not focusable and has no keyboard interaction.
- The line uses the `border` token, a quiet divider that is not required to meet the 3:1 non-text contrast target because it is decorative; if a line is essential to understand the UI, add another cue.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use spacing first and a separator only to group content. | Separate every row of a list with a line. |
| Mark meaningful dividers with `:decorative="false"`. | Use a separator as the only cue that two sections differ. |
| Give vertical separators a parent with a height. | Use `h-px` or `w-px` utilities to build your own. |
