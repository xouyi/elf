## Usage

```vue
<ElfDialog>
  <ElfDialogTrigger as-child><ElfButton variant="outline">Edit</ElfButton></ElfDialogTrigger>
  <ElfDialogContent>
    <ElfDialogHeader>
      <ElfDialogTitle>Edit profile</ElfDialogTitle>
      <ElfDialogDescription>Update your display name.</ElfDialogDescription>
    </ElfDialogHeader>
    <ElfInput aria-label="Display name" />
    <ElfDialogFooter>
      <ElfDialogClose as-child><ElfButton variant="outline">Cancel</ElfButton></ElfDialogClose>
      <ElfButton>Save</ElfButton>
    </ElfDialogFooter>
  </ElfDialogContent>
</ElfDialog>
```

| Part | Notes |
| :-- | :-- |
| `ElfDialog` | Root. Props `open`, `defaultOpen`, `modal`. Emits `update:open`. |
| `ElfDialogTrigger` | Opens the dialog. Use `as-child` with a button. |
| `ElfDialogContent` | Portaled surface. Prop `showCloseButton` (default `true`). |
| `ElfDialogHeader`, `ElfDialogTitle`, `ElfDialogDescription` | Heading structure. |
| `ElfDialogFooter` | Action row. Prop `showCloseButton` adds a Close button. |
| `ElfDialogClose` | Closes the dialog. Use `as-child`. |
| `ElfDialogOverlay` | Backdrop (included by Content). |

::callout{type="info" title="Portals follow the page theme"}
The dialog surface is portaled to the end of `<body>`, so it uses the theme of the page, not the per-example theme toggle of the preview frame.
::

## Accessibility

- Always include `ElfDialogTitle`. Include `ElfDialogDescription` as well, or Reka UI logs an accessibility warning in development (use `class="sr-only"` to hide it visually).
- Focus moves into the dialog on open and returns to the trigger on close. Focus is trapped while it is open and the page behind is inert.
- Animations respect `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>Esc</kbd> | Closes the dialog and returns focus to the trigger. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Cycles through the focusable elements inside the dialog. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused button, including the trigger. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use a dialog for focused tasks and confirmations. | Use a dialog for passive messages. |
| Label destructive confirmations with the action ("Delete"). | Label them "OK". |
| Keep the content short and scrollable. | Stack dialogs on top of each other. |
