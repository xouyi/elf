## Accessibility

- A badge is static text, not interactive. If it must be clickable, render it with `as-child` as a link or button.
- Never rely on color alone: the text must say what the status is ("Live", "Failed").
- Text pairs pass WCAG AA in every theme.

## Theming

Under the nova theme `--elf-radius-pill` is `0`, so badges are rectangular.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use `success`, `warning`, `destructive` for status. | Use badges for primary actions. |
| Keep labels to one or two words. | Put paragraphs inside a badge. |
| Use variants from the theme. | Set custom background colors. |
