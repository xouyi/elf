## Usage

```vue
<script setup lang="ts">
function remove() {
  // delete the match log
}
</script>

<template>
  <ElfAlertDialog>
    <ElfAlertDialogTrigger as-child><ElfButton variant="destructive">Delete</ElfButton></ElfAlertDialogTrigger>
    <ElfAlertDialogContent>
      <ElfAlertDialogHeader>
        <ElfAlertDialogTitle>Delete this match log?</ElfAlertDialogTitle>
        <ElfAlertDialogDescription>This action cannot be undone.</ElfAlertDialogDescription>
      </ElfAlertDialogHeader>
      <ElfAlertDialogFooter>
        <ElfAlertDialogCancel>Keep it</ElfAlertDialogCancel>
        <ElfAlertDialogAction variant="destructive" @click="remove">Delete</ElfAlertDialogAction>
      </ElfAlertDialogFooter>
    </ElfAlertDialogContent>
  </ElfAlertDialog>
</template>
```

| Part | Notes |
| :-- | :-- |
| `ElfAlertDialog` | Root. Props `open`, `defaultOpen`. Emits `update:open`. |
| `ElfAlertDialogTrigger` | Opens the dialog. Use `as-child` with a button. |
| `ElfAlertDialogContent` | Portaled surface with the shared dialog styling. No corner close button. |
| `ElfAlertDialogHeader`, `ElfAlertDialogTitle`, `ElfAlertDialogDescription` | Heading structure. Title and description are required. |
| `ElfAlertDialogFooter` | Action row; the buttons are full height (40px) on small screens. |
| `ElfAlertDialogCancel` | Closes without deciding. Outline button. Receives initial focus. |
| `ElfAlertDialogAction` | Closes and confirms. Prop `variant` (`default` or `destructive`). Handle the decision with `@click`. |

::callout{type="info" title="Alert dialog or dialog?"}
Use `ElfAlertDialog` when the user must answer before continuing. Use `ElfDialog` for forms and any content that may be dismissed by clicking outside.
::

## Accessibility

- The content has `role="alertdialog"`, labelled by the title and described by the description.
- Focus moves to Cancel on open (the safe choice), is trapped while open and returns to the trigger on close.
- A click on the backdrop does nothing; only Cancel, the action or <kbd>Esc</kbd> close the dialog.
- Animations respect `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>Esc</kbd> | Closes the dialog (same as Cancel) and returns focus to the trigger. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Cycles through Cancel and the action. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused button. Because Cancel has focus first, the destructive action needs a deliberate Tab. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Ask for confirmation of irreversible actions only. | Confirm every routine save. |
| Say what will be lost in the description. | Use "Are you sure?" alone. |
| Use `variant="destructive"` for deletions. | Style a harmless action as destructive. |
