## Usage

```vue
<template>
  <ElfPopover>
    <ElfPopoverTrigger as-child>
      <ElfButton variant="outline">Rename item</ElfButton>
    </ElfPopoverTrigger>
    <ElfPopoverContent>
      <ElfLabel for="name">Name</ElfLabel>
      <ElfInput id="name" />
    </ElfPopoverContent>
  </ElfPopover>
</template>
```

`ElfPopover` is built on the Reka UI `Popover` primitive, which provides focus management, dismissal, collision handling and the ARIA wiring. The parts are:

| Part | Purpose |
| :-- | :-- |
| `ElfPopover` | Holds the open state (`v-model:open`) and `modal`. Renders no element. |
| `ElfPopoverTrigger` | The button that toggles the panel. Use `as-child` to wrap your own button. |
| `ElfPopoverAnchor` | Optional. Anchors the panel to another element than the trigger. |
| `ElfPopoverContent` | The panel, rendered in a portal. `side`, `align`, `sideOffset`; it never grows past the viewport and scrolls inside it. |
| `ElfPopoverClose` | Closes the panel. Use `as-child` around a button. |

Unlike a [Tooltip](/docs/components/tooltip), a popover can hold interactive content. By default it is non-modal: the page stays usable and the panel closes when focus or a pointer leaves it. Set `modal` to trap focus and make the page behind inert.

### Mobile

The panel is at most `100vw - 1rem` wide and as tall as the available space, so it fits a 360px screen; give controls inside it the usual 40px touch targets.

## Accessibility

- Follows the WAI-ARIA [Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) pattern: the panel has `role="dialog"`; the trigger has `aria-haspopup="dialog"`, `aria-expanded` and `aria-controls`.
- Focus moves into the panel when it opens and returns to the trigger when it closes.
- Give the panel an accessible name when it has no visible heading (`aria-label` or `aria-labelledby` on `ElfPopoverContent`).
- With `modal`, Tab is trapped in the panel and the page behind is hidden from assistive technology.

| Key | Action |
| :-- | :-- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | On the trigger, opens or closes the panel. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Moves through the controls in the panel. Modal: wraps inside it. Non-modal: moving past the edge closes it. |
| <kbd>Escape</kbd> | Closes the panel and returns focus to the trigger. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Keep content short: a few fields or actions. | Build a whole page in it; use a dialog or sheet. |
| Use `ElfPopoverClose` for an explicit Apply or Done. | Rely on the user clicking outside to commit. |
| Name the panel when it has no heading. | Put only a hint in it; use a tooltip. |
