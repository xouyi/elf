## Usage

Reka UI has no sidebar primitive, so `ElfSidebar` is composed from `ElfSheet` (phones), `ElfTooltip` (labels in the icon rail), `ElfSeparator` and `ElfScrollArea`. The groups and sub menus use native lists, and `ElfCollapsible` makes any group collapsible.

```vue
<ElfSidebarProvider>
  <ElfSidebar collapsible="icon" label="Main navigation">
    <ElfSidebarHeader>…</ElfSidebarHeader>
    <ElfSidebarContent>
      <ElfSidebarGroup>
        <ElfSidebarGroupLabel>Platform</ElfSidebarGroupLabel>
        <ElfSidebarGroupContent>
          <ElfSidebarMenu>
            <ElfSidebarMenuItem>
              <ElfSidebarMenuButton as-child is-active tooltip="Dashboard">
                <NuxtLink to="/"><LayoutDashboard /><span>Dashboard</span></NuxtLink>
              </ElfSidebarMenuButton>
            </ElfSidebarMenuItem>
          </ElfSidebarMenu>
        </ElfSidebarGroupContent>
      </ElfSidebarGroup>
    </ElfSidebarContent>
    <ElfSidebarFooter>…</ElfSidebarFooter>
    <template #rail><ElfSidebarRail /></template>
  </ElfSidebar>
  <ElfSidebarInset>
    <header><ElfSidebarTrigger /></header>
    <slot />
  </ElfSidebarInset>
</ElfSidebarProvider>
```

| Part | Notes |
| :-- | :-- |
| `ElfSidebarProvider` | Layout wrapper and state owner. Props `open` (`v-model:open`), `defaultOpen`, `shortcut`, `storageKey`. Sets `--sidebar-width` (16rem) and `--sidebar-width-icon` (3rem); override them with `style` or a class. Give it a height (`h-96 min-h-0`) when it should not fill the page. |
| `ElfSidebar` | The panel. Props `side`, `variant`, `collapsible`, `label`, `description`. Renders a labelled `<nav>`; below 768px it renders an `ElfSheet` instead. Slot `rail` places an `ElfSidebarRail`. |
| `ElfSidebarHeader`, `ElfSidebarFooter` | Fixed rows above and below the scrolling content. |
| `ElfSidebarContent` | Scrollable middle (an `ElfScrollArea`). |
| `ElfSidebarSeparator` | An `ElfSeparator` that spans the panel. |
| `ElfSidebarGroup`, `ElfSidebarGroupLabel`, `ElfSidebarGroupContent` | A titled section. The label hides in the icon rail; use `as-child` with `ElfCollapsibleTrigger` for a collapsible group. |
| `ElfSidebarMenu`, `ElfSidebarMenuItem` | The list (`ul` and `li`). |
| `ElfSidebarMenuButton` | The row. Props `isActive`, `tooltip`, `variant`, `size`, `as` and `asChild`. Put the icon first and the label in the last `<span>`. |
| `ElfSidebarMenuBadge` | A count on the right of an item (place it inside `ElfSidebarMenuItem`). |
| `ElfSidebarMenuSub`, `ElfSidebarMenuSubItem`, `ElfSidebarMenuSubButton` | A nested list under an item; hidden in the icon rail. |
| `ElfSidebarTrigger` | Icon button that toggles the sheet on phones and the sidebar on desktop. Prop `label`. |
| `ElfSidebarRail` | A thin hit area on the sidebar edge that toggles it with the pointer. |
| `ElfSidebarInset` | The main area (`<main>`). With `variant="inset"` it becomes a rounded card. |

`useSidebar()` returns `{ state, open, setOpen, openMobile, setOpenMobile, isMobile, toggleSidebar }` inside a provider, for custom triggers (for example a bottom bar button) and layouts. It throws outside `ElfSidebarProvider`.

::callout{type="info" title="Phones"}
Below 768px (Tailwind `md`) the sidebar is an off-canvas sheet that always shows full labels, covers at most the screen minus a 40px strip of the page, and closes when a link is chosen. Rows are 40px tall there. `collapsible="none"` opts out and stays a static column.
::

## Examples

### Collapse to icons

`collapsible="icon"` shrinks the panel to an icon rail. Give every menu button a `tooltip`: it appears on hover and keyboard focus only while the rail is collapsed. The default example above uses it together with `ElfSidebarRail`.

### Off-canvas

The default `collapsible="offcanvas"` slides the whole panel away. Its links leave the tab order while it is closed.

::component-preview{name="sidebar-offcanvas"}
::

### Controlled and persisted

Bind `v-model:open` to drive the sidebar from anywhere. `storage-key` remembers the desktop state in `localStorage`; it is applied after mount so server-rendered markup and hydration agree.

::component-preview{name="sidebar-controlled"}
::

### Variants and sides

`variant` is `sidebar` (flush with a border), `floating` (an inset card) or `inset` (the main area becomes a card inside the sidebar surface). `side` is `left` or `right`.

::component-preview{name="sidebar-variants"}
::

### Collapsible groups and sub menus

Wrap a group in `ElfCollapsible` and render the label with `as-child` around `ElfCollapsibleTrigger`, or nest `ElfSidebarMenuSub` inside an item.

::component-preview{name="sidebar-collapsible-groups"}
::

## Accessibility

- The panel is a `<nav>` named by `label` (use your app language). With several navigations on a page, give each a different label.
- Mark the current page with `is-active`: it sets `aria-current="page"`. Use real links through `as-child` so routing, middle click and "open in new tab" work.
- On phones the sheet is a modal dialog: focus moves in, is trapped, `Esc` closes it and focus returns to the trigger. It has a title (`label`) and a hidden description.
- `ElfSidebarTrigger` has an accessible name (`label`) and reports `aria-expanded`. The rail is pointer only (`tabindex="-1"`); the trigger and the shortcut cover the keyboard.
- Icon-only rows keep their accessible name. The shortcut is ignored while focus is in a text field.
- Width and slide animations stop under `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>B</kbd> | Toggles the sidebar (the sheet on phones). Change the key with `shortcut`, or turn it off with `:shortcut="false"`. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Moves through the trigger and the links in reading order; a closed off-canvas sidebar is skipped. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates a link or button; on a collapsible trigger it opens or closes the group. |
| <kbd>Esc</kbd> | Closes the phone sheet, or a tooltip. |

## Theming

The sidebar uses the standard surface tokens: `card` for the panel, `accent` for hover and the active row, `muted-foreground` for group labels, `primary` for badges and `ring` for focus, so it works in every theme. A dedicated `--sidebar-*` token set is planned for the theme utilities.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Put the label in the last `<span>` of a menu button so it truncates and hides cleanly in the icon rail. | Rely on the tooltip alone to name an icon: the text must stay in the DOM. |
| Give each icon row a `tooltip` when using `collapsible="icon"`. | Put essential actions only in a hover-only control. |
| Keep top-level items to a short list and group the rest. | Nest more than one level of sub menu. |
| Translate `label`, `description` and the trigger `label` for your audience. | Leave the English defaults on a Turkish UI. |
