## Usage

```vue
<script setup lang="ts">
const subteam = ref('software')
</script>

<template>
  <ElfRadioGroup v-model="subteam" aria-label="Subteam">
    <div class="flex items-center gap-3">
      <ElfRadioGroupItem id="mech" value="mechanical" />
      <ElfLabel for="mech">Mechanical</ElfLabel>
    </div>
    <div class="flex items-center gap-3">
      <ElfRadioGroupItem id="soft" value="software" />
      <ElfLabel for="soft">Software</ElfLabel>
    </div>
  </ElfRadioGroup>
</template>
```

`ElfRadioGroup` is built on the Reka UI `RadioGroup` primitive; `ElfRadioGroupItem` is one option. Reka provides the roving tab stop, arrow-key selection and the hidden form inputs (set `name` on the group to submit it with a native form). Give the group a name with `aria-label`, `aria-labelledby` or a [Field](/docs/components/field) label, and give every item a [Label](/docs/components/label) (the item first, so `peer-disabled` dims the label).

The item is always a circle, even in the sharp `novatron` theme, so that it stays distinguishable from a [Checkbox](/docs/components/checkbox).

## Accessibility

- Follows the WAI-ARIA [Radio group](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) pattern: a `role="radiogroup"` element containing `role="radio"` buttons with `aria-checked`.
- Only one radio is in the Tab order (the checked one, or the first when none is checked); arrow keys move between the options.
- `invalid` or a Field error sets `aria-invalid="true"` on the group and turns every border destructive; the message states the problem.
- Inside a Field with `required`, the group has `aria-required="true"`.
- Borders use the `input` token (3:1 against the background); focus draws a ring in the `ring` token.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus into the group (to the checked radio, or the first one) and out of it. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowRight</kbd> | Moves focus to the next radio and checks it. Wraps from last to first. |
| <kbd>ArrowUp</kbd> / <kbd>ArrowLeft</kbd> | Moves focus to the previous radio and checks it. Wraps from first to last. |
| <kbd>Space</kbd> | Checks the focused radio. |
| Click on the label | Checks the radio. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Preselect the safest or most common option. | Leave a required group empty without saying it is required. |
| Use a radio group for two to six exclusive options. | Use radios for a long list; use a select. |
| Label the group as well as each option. | Rely on layout alone to show which options belong together. |
| Use checkboxes when several options may be chosen. | Use radios for independent on/off choices. |
