## Usage

```vue
<script setup lang="ts">
const open = ref(false)
</script>

<template>
  <ElfCollapsible v-model:open="open">
    <ElfCollapsibleTrigger as-child><ElfButton variant="outline">Filters</ElfButton></ElfCollapsibleTrigger>
    <ElfCollapsibleContent>Season, event and alliance filters.</ElfCollapsibleContent>
  </ElfCollapsible>
</template>
```

| Part | Notes |
| :-- | :-- |
| `ElfCollapsible` | Root. Props `open`, `defaultOpen`, `disabled`. Emits `update:open`. |
| `ElfCollapsibleTrigger` | Toggles the region. Use `as-child` with a button; it gets `aria-expanded` and `aria-controls`. |
| `ElfCollapsibleContent` | The region. The height animates from 0 to its natural height and back. |

::callout{type="tip" title="Several related sections?"}
Use `ElfAccordion` for a stack of collapsible sections with arrow-key navigation.

## Accessibility

- The trigger is a button with `aria-expanded` and `aria-controls`. Give an icon-only trigger an `aria-label`.
- Closed content is hidden from assistive technology and the tab order.
- The height animation stops under `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Toggles the region. |
| <kbd>Tab</kbd> | Moves focus to the trigger and into the open content. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Keep the trigger next to the content it controls. | Hide required form fields in a closed region. |
| Name the trigger after the content. | Use a bare chevron without a label. |
