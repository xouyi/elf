## Usage

```vue
<script setup lang="ts">
const value = ref(64)
</script>

<template>
  <ElfProgress v-model="value" label="Uploading roster.csv" />
</template>
```

`ElfProgress` is built on the Reka UI `Progress` primitive: a `role="progressbar"` element with `aria-valuenow`, `aria-valuemin="0"` and `aria-valuemax` (`max`, default 100). The indicator width follows `value / max`. For a task of unknown length pass `null`: the bar becomes indeterminate.

A progress bar **needs a name**. Use the `label` prop (or `aria-label`) when there is no visible text, or `aria-labelledby` pointing at the visible label.

## Examples

### Indeterminate

`:model-value="null"` removes `aria-valuenow`, so assistive technology announces a busy bar without a number, and the indicator slides. Under `prefers-reduced-motion` it becomes a static half-opacity bar.

### With a visible label

Point `aria-labelledby` at the visible label. `get-value-text` sets `aria-valuetext`, a more meaningful reading than a percentage ("7 of 12 tasks done").

## Accessibility

- Uses `role="progressbar"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`; an indeterminate bar omits `aria-valuenow`.
- The accessible name comes from `label`, `aria-label` or `aria-labelledby`. When none is given, the bar is named by its percentage ("64%"), which is not descriptive; always provide a name.
- Screen readers do not announce progress changes by themselves. When the user needs to know that work finished, announce it through a status message (for example an [Alert](/docs/components/alert) added to the page).
- The indicator uses the `primary` token on a `secondary` track; the indicator meets 3:1 against the page background in both themes. The value is also present in text next to the bar when it matters.
- The sliding animation of the indeterminate state is removed under `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | A progress bar is not interactive and is skipped. |

## Theming

::component-tokens{component="progress"}
::

The track radius uses `--elf-radius-pill`: rounded in `elf`, square in `nova`. Change the indicator color with `indicator-class`, for example `bg-success`.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Name every bar and show the number nearby for long tasks. | Show an unlabeled bar. |
| Use an indeterminate bar when you cannot estimate the time. | Fake a determinate value. |
| Use `get-value-text` for counts ("7 of 12"). | Rely on the percentage when the real unit is something else. |
| Use a [Spinner](/docs/components/spinner) for short, inline waits. | Use a progress bar for waits under a second. |
