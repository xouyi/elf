## Usage

```vue
<template>
  <ElfNavigationMenu aria-label="Main">
    <ElfNavigationMenuList>
      <ElfNavigationMenuItem>
        <ElfNavigationMenuTrigger>Learn</ElfNavigationMenuTrigger>
        <ElfNavigationMenuContent>
          <ul class="grid w-64 gap-1">
            <li>
              <ElfNavigationMenuLink href="/courses">
                <span class="font-medium">Courses</span>
                <span class="text-muted-foreground">Training for every subteam.</span>
              </ElfNavigationMenuLink>
            </li>
          </ul>
        </ElfNavigationMenuContent>
      </ElfNavigationMenuItem>
      <ElfNavigationMenuItem>
        <ElfNavigationMenuLink href="/docs" variant="trigger">
          Docs
        </ElfNavigationMenuLink>
      </ElfNavigationMenuItem>
    </ElfNavigationMenuList>
  </ElfNavigationMenu>
</template>
```

`ElfNavigationMenu` is built on the Reka UI `NavigationMenu` primitive. It renders a `nav` landmark. Reka UI handles hover intent, the delay between triggers, outside dismissal and the arrow-key movement along the top level.

| Part | Purpose |
| :-- | :-- |
| `ElfNavigationMenu` | The `nav` landmark. Holds `v-model`, the hover delays and `viewport`. |
| `ElfNavigationMenuList` | The list of top-level items. |
| `ElfNavigationMenuItem` | One top-level entry: a trigger with a panel, or a link. |
| `ElfNavigationMenuTrigger` | A button that opens the panel of its item; adds a chevron. |
| `ElfNavigationMenuContent` | The flyout panel. Put links, grids or any content in it. |
| `ElfNavigationMenuLink` | A link. `variant="item"` (default) is for panels, `variant="trigger"` looks like a trigger for top-level links. `active` marks the current page. |
| `ElfNavigationMenuViewport` | The surface the panels grow from. Rendered for you unless `viewport` is `false`. |
| `ElfNavigationMenuIndicator` | Optional arrow that follows the open trigger. Put it inside the list. |

Links render an `a`. For a router link use `as-child` and put `NuxtLink` or `RouterLink` inside; the helpers `navigationMenuTriggerStyle()` and `navigationMenuItemLinkClass` are exported when you need the classes on your own element.

### Mobile

A flyout bar suits wide screens. The top-level items wrap onto more lines on small screens, triggers are 40px tall below the `md` breakpoint, and the panel is clamped to stay inside the viewport. For a long list of destinations on a phone, prefer a [Sheet](/docs/components/sheet) with a plain list of links.

## Accessibility

- A navigation menu is **not** an ARIA menu. It follows the [disclosure navigation](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/) pattern: the root is a `nav` landmark, triggers are buttons with `aria-expanded`, and panels contain ordinary links that stay in the Tab order. Do not add `role="menu"`.
- The current page is marked with `active`, which sets `aria-current="page"` and `data-active`.
- Give the `nav` an `aria-label` when the page has more than one navigation landmark.
- Panels open on hover and on click, so touch and keyboard users reach them too. Do not hide a destination that exists nowhere else behind hover only.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves to the next top-level item, or into the links of the open panel. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | On a trigger, opens or closes its panel. On a link, follows it. |
| <kbd>ArrowRight</kbd> / <kbd>ArrowLeft</kbd> | Moves between top-level items. |
| <kbd>ArrowDown</kbd> | On an open trigger, moves into its panel. |
| <kbd>Escape</kbd> | Closes the panel and returns focus to its trigger. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Keep panels to a few links with short descriptions. | Put forms or dense tables in a flyout. |
| Mark the current page with `active`. | Style the current page with a class only. |
| Offer the same destinations on a small screen, for example in a Sheet. | Rely on the flyout alone on phones. |
