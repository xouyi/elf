## Usage

```vue
<template>
  <ElfMenubar>
    <ElfMenubarMenu>
      <ElfMenubarTrigger>File</ElfMenubarTrigger>
      <ElfMenubarContent>
        <ElfMenubarItem>
          Save
          <ElfMenubarShortcut><ElfKbd>Ctrl</ElfKbd><ElfKbd>S</ElfKbd></ElfMenubarShortcut>
        </ElfMenubarItem>
        <ElfMenubarSeparator />
        <ElfMenubarItem variant="destructive">Delete</ElfMenubarItem>
      </ElfMenubarContent>
    </ElfMenubarMenu>
  </ElfMenubar>
</template>
```

`ElfMenubar` is built on the Reka UI `Menubar` primitive. It has the same item parts as the [Dropdown Menu](/docs/components/dropdown-menu) (`Item`, `CheckboxItem`, `RadioGroup`, `RadioItem`, `Label`, `Group`, `Separator`, `Shortcut`, `Sub`, `SubTrigger`, `SubContent`) and the same styles: both are built from the helpers exported by the dropdown menu module, so this component depends on it in the registry.

| Part | Purpose |
| :-- | :-- |
| `ElfMenubar` | The bar (`role="menubar"`). Holds `v-model` (the open menu), `loop` and `dir`. |
| `ElfMenubarMenu` | One menu: a trigger and its content. Renders no element. |
| `ElfMenubarTrigger` | The label of the menu on the bar. |
| `ElfMenubarContent` and the item parts | As in the Dropdown Menu. |

A menubar is for the commands of an application or an editor. For site navigation use the [Navigation Menu](/docs/components/navigation-menu); for one button with actions use the [Dropdown Menu](/docs/components/dropdown-menu).

### Mobile

The bar is as wide as its triggers; keep the number of menus small so it fits a phone. Item rows are 40px high below the `md` breakpoint and menus stay inside the viewport.

## Accessibility

- Follows the WAI-ARIA [Menubar](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/) pattern: the bar has `role="menubar"`, the triggers are `menuitem`s with `aria-haspopup="menu"` and `aria-expanded`, and the menus use `role="menu"` with `menuitem`, `menuitemcheckbox` or `menuitemradio` rows.
- The bar is a single tab stop (roving focus). Focus returns to the trigger when a menu closes.
- Once a menu is open, moving the pointer over another trigger opens that one instead.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus onto the bar, and off it. |
| <kbd>ArrowRight</kbd> / <kbd>ArrowLeft</kbd> | On the bar, moves to the next or previous trigger (wraps). In an open menu, switches to the neighbouring menu, or opens and closes a sub menu. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> | On a trigger, opens its menu and focuses the first item. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | Moves to the next or previous item. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Focuses the first or last item. |
| Typing | Typeahead: focuses the next item whose text starts with the typed characters. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | On an item, activates it and closes the menu. |
| <kbd>Escape</kbd> | Closes the menu and returns focus to its trigger. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use it for the commands of an editor or tool. | Use it for website navigation. |
| Show shortcuts with `ElfMenubarShortcut`. | Put an essential action only in a menubar on a touch-first page. |
| Keep the bar to a few short menus. | Let the bar grow wider than a phone screen. |
