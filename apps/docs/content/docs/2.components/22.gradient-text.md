## Usage

```vue
<h1>Build with <ElfGradientText variant="aurora">accessible components</ElfGradientText></h1>
```

`ElfGradientText` renders a `span` by default. Use `as` for another element, or `as-child` to style your own element. It sets `bg-clip-text` and `text-transparent` over a `linear-gradient`, so the text is still real text: selectable, searchable and read as written.

## Examples

### Variants

`brand` blends the theme's primary colour into its foreground colour, so it follows every theme. `aurora`, `sunset` and `forest` have a light and a dark set of stops chosen with `light-dark()`, so they switch with the theme's `color-scheme`.

::component-preview{name="gradient-text-variants"}
::

### Custom colours

`from`, `via` and `to` take any CSS colour, including theme tokens. They override the stops of the preset.

::component-preview{name="gradient-text-custom"}
::

### Animated

`animate` shifts the gradient slowly back and forth. The animation is removed when the user prefers reduced motion.

## Accessibility

- The text is real text in the DOM: screen readers read it as written and users can select and copy it.
- Every stop of every preset is tested to reach 4.5:1 against the `background`, `card` and `popover` colours of each theme (`GradientText.test.ts`). No preset is limited to large text.
- Custom `from`, `via` and `to` colours are not checked for you. Keep 4.5:1 against the surface, or 3:1 when the text is large (24px, or 18.66px bold).
- In `forced-colors` mode (Windows High Contrast) the gradient is dropped and the text uses `CanvasText`.
- The shimmer is decorative and stops under `prefers-reduced-motion`.
- Gradient text is not interactive and not focusable. Put it inside a link or button for that, and keep the contrast of the focus ring.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Gradient text is not focusable and is skipped. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use it for a few words in a heading. | Colour whole paragraphs with a gradient. |
| Pick a preset, or check custom colours for 4.5:1. | Use pale stops on a light theme. |
| Keep the text meaningful on its own. | Hide information in the gradient colours alone. |
