## Usage

```vue
<script setup lang="ts">
import { Trash2 } from '@lucide/vue'
</script>

<template>
  <ElfButton variant="outline" size="icon">
    <Trash2 />
    <ElfVisuallyHidden>Delete item</ElfVisuallyHidden>
  </ElfButton>
</template>
```

Reka UI provides the primitive, so ElfUI only forwards its props and adds `data-slot="visually-hidden"` and `class`.

## Accessibility

- The content stays in the accessibility tree: screen readers announce it and it can name its parent control.
- `feature="focusable"` (default) only hides visually; any focusable child keeps its place in the tab order. `feature="fully-hidden"` also sets `aria-hidden="true"` and `tabindex="-1"`, for helpers that must not be announced.
- Do not use `display: none`, `hidden` or `visibility: hidden` for content assistive technology must read; they remove it from the accessibility tree.
- There is no dedicated keyboard interaction and no ARIA role: the element is a plain `span` unless you change it with `as`.

## Theming

The component draws nothing, so it reads no theme tokens.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Give icon-only buttons a hidden text label. | Leave an icon-only control without a name. |
| Keep the hidden text short and specific ("Delete item"). | Hide long passages of content that sighted users never see. |
| Prefer a visible label when space allows. | Hide a label only to save a line of layout. |
| Use `as="caption"` for hidden table captions. | Use `display: none` on text that must be announced. |
