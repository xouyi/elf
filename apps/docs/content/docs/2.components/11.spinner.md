## Usage

```vue
<ElfSpinner />
<ElfSpinner size="lg" label="Loading the match schedule" />
```

Reka UI has no spinner, so `ElfSpinner` is composed from an inline SVG and [Visually Hidden](/docs/components/visually-hidden) for the announced text. The ring uses `currentColor`; set the color with a text utility such as `text-primary`.

## Accessibility

- The root has `role="status"`, an implicit polite live region. The `label` (default "Loading") is visually hidden text inside it.
- Live regions announce **changes**. Mount the spinner when the work starts (`v-if`) rather than shipping it hidden in the initial page, so the announcement happens.
- The SVG is `aria-hidden`; only the label is exposed.
- Animation stops under `prefers-reduced-motion: reduce`; the ring is still visible, and the label carries the message.
- Write a specific label ("Saving changes") when several spinners can be on screen.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | The spinner is not focusable. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use a spinner for waits of unknown length. | Use it for progress you can measure. |
| Pair it with text in buttons ("Saving"). | Show a spinner as the only content of a wide area; use a skeleton for layout. |
| Disable the control that started the work. | Leave a busy button clickable. |
