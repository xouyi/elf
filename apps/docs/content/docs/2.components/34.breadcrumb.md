## Usage

Reka UI has no breadcrumb primitive, so this component is composed from native elements (`nav`, `ol`, `li`, `a`) and `Primitive`.

```vue
<ElfBreadcrumb>
  <ElfBreadcrumbList>
    <ElfBreadcrumbItem>
      <ElfBreadcrumbLink href="/">Home</ElfBreadcrumbLink>
    </ElfBreadcrumbItem>
    <ElfBreadcrumbSeparator />
    <ElfBreadcrumbItem>
      <ElfBreadcrumbPage>Breadcrumb</ElfBreadcrumbPage>
    </ElfBreadcrumbItem>
  </ElfBreadcrumbList>
</ElfBreadcrumb>
```

Use `as-child` on `ElfBreadcrumbLink` to render a router link:

```vue
<ElfBreadcrumbLink as-child>
  <NuxtLink to="/components">Components</NuxtLink>
</ElfBreadcrumbLink>
```

## Accessibility

Follows the WAI-ARIA breadcrumb pattern: a `nav` landmark named by `aria-label` (default `Breadcrumb`; translate it and keep it unique when a page has several trails) containing an ordered list. The last item is `ElfBreadcrumbPage` with `aria-current="page"`; it is not focusable. There is no custom keyboard model: links are ordinary Tab stops.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Moves between the links of the trail. |
| <kbd>Enter</kbd> | Follows the focused link, or opens the collapsed levels menu from the ellipsis. |
| <kbd>Up</kbd> / <kbd>Down</kbd> | Moves between the items of the collapsed levels menu. |
| <kbd>Escape</kbd> | Closes the collapsed levels menu and returns focus to the ellipsis. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Show the path from the root to the current page. | Use a breadcrumb as the only navigation. |
| Keep labels short and identical to page titles. | Link the current page. |
| Collapse middle levels first and keep the root and parent visible. | Hide the parent of the current page. |
