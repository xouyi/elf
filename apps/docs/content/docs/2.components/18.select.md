## Usage

```vue
<script setup lang="ts">
const subteam = ref('')
</script>

<template>
  <ElfLabel for="subteam">Subteam</ElfLabel>
  <ElfSelect v-model="subteam">
    <ElfSelectTrigger id="subteam">
      <ElfSelectValue placeholder="Choose a subteam" />
    </ElfSelectTrigger>
    <ElfSelectContent>
      <ElfSelectItem value="mechanical">Mechanical</ElfSelectItem>
      <ElfSelectItem value="software">Software</ElfSelectItem>
    </ElfSelectContent>
  </ElfSelect>
</template>
```

`ElfSelect` is built on the Reka UI `Select` primitive, which provides the select-only combobox pattern: focus management, typeahead, dismissal, collision handling and the hidden native `<select>` for form submission (set `name`). The parts are:

| Part | Purpose |
| :-- | :-- |
| `ElfSelect` | Holds the value (`v-model`) and the open state (`v-model:open`). Renders no element. |
| `ElfSelectTrigger` | The button that shows the value. `size` is `default` or `sm`; `invalid` flags it. |
| `ElfSelectValue` | The selected item's text, or the `placeholder`. |
| `ElfSelectContent` | The popup, rendered in a portal. Positioned below the trigger at the trigger's width, flipped when there is no room. |
| `ElfSelectItem` | One option. `value` is required; `disabled` is supported. |
| `ElfSelectGroup`, `ElfSelectLabel`, `ElfSelectSeparator` | Group options under a heading and divide them. |
| `ElfSelectScrollUpButton`, `ElfSelectScrollDownButton` | Rendered by `ElfSelectContent`; shown only when the list scrolls. |

Reka UI's `item-aligned` mode (the list overlaps the trigger like a macOS menu) is available through `position="item-aligned"`, but the default is `popper`, which stays inside the viewport on phones. For a very short, fixed list prefer a [Radio Group](/docs/components/radio-group).

### Mobile

The trigger and the options use 16px text below the `md` breakpoint (so iOS does not zoom when the field is focused) and larger option rows; the popup never exceeds the available viewport height and scrolls inside it.

## Accessibility

- Follows the WAI-ARIA select-only [combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/) pattern: the trigger has `role="combobox"` with `aria-expanded` and `aria-controls`; the popup is a `role="listbox"` of `role="option"` items with `aria-selected`.
- The trigger needs an accessible name: a `<label for>` pointing at its `id`, a Field label, or `aria-label`. The selected value alone is not a name.
- Inside a Field with `required`, the trigger has `aria-required="true"`; `invalid` or a Field error sets `aria-invalid="true"`.
- While open, the page behind is inert to pointer input and scrolling is locked. Escape closes the popup and returns focus to the trigger.
- Highlighted options use the `accent` token and the selected option shows a check mark, so selection is never color-only.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the trigger. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Opens the popup with the selected option highlighted; inside the popup, selects the highlighted option and closes. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | On the trigger, opens the popup. In the popup, moves the highlight. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Highlights the first or last option. |
| Typing | Typeahead: highlights the next option whose text starts with the typed characters (on the closed trigger it changes the value). |
| <kbd>Escape</kbd> | Closes the popup without changing the value. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use a select for five or more options, or when space is limited. | Use a select for two or three options; use a radio group. |
| Give a placeholder that names the choice ("Choose a subteam"). | Use the placeholder as the label. |
| Group long lists with `ElfSelectGroup` and a label. | Put an unordered list of dozens of options in a select without grouping or search. |
| Wrap only the trigger in `ElfFieldControl`. | Wrap the whole `ElfSelect`. |
