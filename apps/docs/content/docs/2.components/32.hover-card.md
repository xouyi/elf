## Usage

```vue
<template>
  <ElfHoverCard>
    <ElfHoverCardTrigger as-child>
      <a href="/members/ayse">Ayşe Demir</a>
    </ElfHoverCardTrigger>
    <ElfHoverCardContent>Software lead. Joined in 2025.</ElfHoverCardContent>
  </ElfHoverCard>
</template>
```

`ElfHoverCard` is built on the Reka UI `HoverCard` primitive, which provides the open and close delays, the pointer grace area, dismissal and collision handling. It shares its panel styling with [Popover](/docs/components/popover). The parts are:

| Part | Purpose |
| :-- | :-- |
| `ElfHoverCard` | Holds the open state (`v-model:open`), `openDelay` (700 ms) and `closeDelay` (300 ms). Renders no element. |
| `ElfHoverCardTrigger` | The link that is previewed. Renders an `a`; the trigger must be a real link that works on its own. |
| `ElfHoverCardContent` | The preview panel, rendered in a portal. `side`, `align`, `sideOffset`. |

A hover card is an enhancement. The same information must be reachable another way (the page the link points to): it never opens on touch devices and is not announced by screen readers. Put nothing in it that a user needs, and nothing interactive.

### Mobile

Touch screens do not hover, so the card never opens there; the link simply navigates. The panel is limited to the viewport width in case it opens on a small window.

## Accessibility

- Follows the spirit of the WAI-ARIA [Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) pattern, but the content is supplementary: it is not exposed as a dialog or tooltip and holds no focusable elements.
- Opens on keyboard focus of the link as well as on hover, and closes on Escape or when focus leaves.
- Never the only way to reach content: the trigger must be a link with its own destination.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Focuses the link and opens the card after the delay. |
| <kbd>Escape</kbd> | Closes the card. Focus stays on the link. |
| <kbd>Enter</kbd> | Follows the link. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use it to preview a person, team or page behind a link. | Hide required information or actions in it. |
| Keep it short and non-interactive. | Put buttons or form fields in it; use a popover. |
| Make the trigger a working link. | Use a button that does nothing else. |
