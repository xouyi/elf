## Usage

```vue
<ElfLabel for="email">Email</ElfLabel>
<ElfInput id="email" type="email" />
```

## Examples

### Required

Mark the requirement visually with an `aria-hidden` asterisk and set `required` on the control, so assistive technology announces it once.

### Disabled

Place the control before the label in the DOM and give it the `peer` class. The label dims through `peer-disabled`. Inside a `group` with `data-disabled="true"` it dims as well.

## Accessibility

- A `<label for>` gives the control its accessible name and enlarges its click target: clicking the label focuses a text control or toggles a checkbox.
- The label text is the name that screen readers announce. Keep it short and unique within the form.
- Reka UI prevents text selection when the label is double-clicked, which would otherwise happen while toggling a checkbox.
- Do not hide the label with `display: none`. If it must not be visible, wrap the text in [Visually Hidden](/docs/components/visually-hidden).

| Key | Action |
| :-- | :-- |
| Click | Moves focus to, or toggles, the associated control. |
| <kbd>Tab</kbd> | Labels are not focusable; focus goes to the control. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Connect every control with `for` and a matching `id`. | Use a placeholder instead of a label. |
| Keep labels visible. | Use a label without a control. |
| Mark required fields with text or `required`. | Rely on a red asterisk alone. |
