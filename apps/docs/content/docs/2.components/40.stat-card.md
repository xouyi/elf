## Usage

```vue
<ElfStatCard
  label="Active members"
  value="48"
  trend="+6"
  trend-direction="up"
  trend-label="up 6 since last month"
  hint="since last month"
/>
```

`ElfStatCard` is composed from [Card](/docs/components/card)-style styling, [Skeleton](/docs/components/skeleton) and [Visually Hidden](/docs/components/visually-hidden); there is no Reka UI primitive for it. The card is a `group` named by its label.

| Prop | Purpose |
| :-- | :-- |
| `label`, `value`, `hint` | The metric name, the figure and supporting text. The `label`, default and `hint` slots replace them. |
| `trend`, `trendDirection`, `trendLabel` | Change since the last period with an arrow (`up`, `down`, `flat`). `trendLabel` is the sentence screen readers read instead of the bare text. |
| `tone` | `default`, `success`, `warning` or `destructive`: tints the border and the trend. |
| `loading`, `loadingLabel` | Shows skeletons instead of the value and sets `aria-busy`. |

### Linking the card

Put `ElfStatCardLink` in the `label` slot. It renders an anchor whose clickable area is stretched over the whole card, so there is a single link and a single tab stop. Use `as-child` to render a router link such as `NuxtLink`.

```vue
<ElfStatCard value="12" hint="waiting for approval">
  <template #label>
    <ElfStatCardLink as-child>
      <NuxtLink to="/requests">Pending requests</NuxtLink>
    </ElfStatCardLink>
  </template>
</ElfStatCard>
```

### Mobile

Place cards in a grid that is one column on small screens, as the examples do (`grid sm:grid-cols-3`). A card never has a fixed width, so it fills its cell.

## Accessibility

- The card is a `group` labelled by its label text, with native paragraphs inside. There is no APG pattern and no keyboard interaction unless it contains a link.
- A linked card has exactly one link; focusing it draws the focus ring around the whole card.
- Color never carries the meaning alone: the `tone` tints the border and the trend, while `trendLabel` and `hint` say the same thing in words.
- While `loading`, the card has `aria-busy="true"` and a polite status message (`loadingLabel`, English by default; translate it).

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Focuses the link of a linked card. |
| <kbd>Enter</kbd> | Follows the link. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use a short, specific label. | Put a sentence in the label. |
| Format the value yourself (units, locale). | Pass raw unformatted numbers. |
| Explain the trend in `trendLabel`. | Rely on the arrow or the color. |
