## Accessibility

- Renders a native `<button>`, so it joins the tab order and Enter and Space activate it.
- A visible focus ring (3:1 contrast, verified per theme) appears on keyboard focus.
- Icon-only buttons (`size="icon"`) **must** have an `aria-label`.
- `disabled` removes the button from interaction and lowers its opacity. Explain why nearby; do not rely on a tooltip.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the button. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the button. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use one `default` button per view for the primary action. | Fill a view with several `default` buttons. |
| Use `destructive` for irreversible actions, confirmed in a [Dialog](/docs/components/dialog). | Use `destructive` for ordinary cancel actions. |
| Use `as-child` with a link for navigation. | Put an `onclick` navigation on a button. |
| Pick a variant with the prop. | Recolor with `bg-*` classes. |
