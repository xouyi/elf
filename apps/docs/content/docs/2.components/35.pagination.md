## Usage

`ElfPagination` takes the total number of items and the page size; it derives the page count. Bind the current page with `v-model:page`. Render the pages from the `items` slot prop of `ElfPaginationContent`.

```vue
<ElfPagination v-model:page="page" :total="100" :items-per-page="10">
  <ElfPaginationContent v-slot="{ items }">
    <ElfPaginationPrev />
    <template v-for="(item, i) in items" :key="i">
      <ElfPaginationItem v-if="item.type === 'page'" :value="item.value" />
      <ElfPaginationEllipsis v-else />
    </template>
    <ElfPaginationNext />
  </ElfPaginationContent>
</ElfPagination>
```

`siblingCount` (default `1`) sets how many pages show on each side of the current page, and `showEdges` (default `true`) always shows the first and last page. These defaults differ from Reka UI (`2` and `false`) to fit narrow screens.

## Accessibility

Pagination is a `nav` landmark (name it with `aria-label`, default `Pagination`) containing a list of native buttons. The current page has `aria-current="page"`; each page button is named "Page N". Previous and next are disabled on the first and last page. There is no dedicated WAI-ARIA pattern: it uses standard navigation landmark and button semantics, so there is no custom keyboard model.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Moves between the enabled buttons. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Goes to the focused page, or the previous or next page. |

Disabled buttons are skipped by Tab. Move focus to the start of the refreshed content yourself if a page change replaces a large region.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Show the current page and total in a status text. | Show every page number for hundreds of pages. |
| Keep the controls in the same place across pages. | Hide the controls when there is a single page and the list can grow. |
| Reset to page 1 when filters change. | Rely on color alone to show the current page. |
