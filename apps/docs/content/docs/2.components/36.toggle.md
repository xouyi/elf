## Usage

A single toggle holds a boolean. A group holds one value (`type="single"`) or several (`type="multiple"`).

```vue
<ElfToggle v-model="bold" aria-label="Toggle bold">
  <Bold />
</ElfToggle>

<ElfToggleGroup v-model="sort" type="single" aria-label="Sort posts">
  <ElfToggleGroupItem value="newest">Newest</ElfToggleGroupItem>
  <ElfToggleGroupItem value="top">Top</ElfToggleGroupItem>
</ElfToggleGroup>
```

## Accessibility

A single toggle is a button with `aria-pressed`. A group (single or multiple) renders `role="group"` and its items are toggle buttons with `aria-pressed`; a `single` group lets at most one be pressed. Name the group with `aria-label` and every icon-only item with `aria-label`. The pressed state is also exposed as `data-state="on"`, so it is not conveyed by colour alone through the role and state.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the toggle, or into the group (one tab stop). |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | Presses or releases the focused toggle. |
| <kbd>Left</kbd> / <kbd>Right</kbd> | Moves focus to the previous or next item in a group, wrapping at the ends. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Moves focus to the first or last item in a group. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use a toggle for a setting that applies at once. | Use a toggle for an action (use a button) or a form on/off value (use a switch). |
| Give icon-only toggles an `aria-label`. | Rely on the icon alone to name the control. |
| Use a `single` group for filters and sort options. | Use a group for navigation (use tabs). |
