## Usage

```vue
<ElfAvatar>
  <ElfAvatarImage src="/members/ayse.jpg" alt="Ayşe Demir" />
  <ElfAvatarFallback name="Ayşe Demir" />
</ElfAvatar>
```

`ElfAvatar` is built on the Reka UI `Avatar` primitive. `ElfAvatarImage` keeps its `<img>` hidden until it has loaded; until then, and when it fails, `ElfAvatarFallback` is shown. Pass `name` to the fallback to show initials (first letters of the first and last word), or put any content in its slot (an icon, `+3`). `delay-ms` on the fallback avoids a flash of initials for images that load quickly.

## Examples

### Fallback

Without an image, the fallback is the avatar. When the person's name is written next to it, the initials only repeat it and need no further label. When the avatar stands alone, set `label` so it is announced as one image with a name.

::component-preview{name="avatar-fallback"}
::

### Sizes

`sm` (24px), `default` (32px), `lg` (40px) and `xl` (56px). The initials scale with the size.

::component-preview{name="avatar-sizes"}
::

### Group

`ElfAvatarGroup` overlaps its avatars and draws a ring in the background color between them. Give the group an `aria-label` that says how many people it represents.

## Accessibility

- Always give `ElfAvatarImage` an `alt`: the person's name when it stands alone, or `alt=""` when the name is shown beside it.
- `label` on `ElfAvatar` makes the whole avatar a single `role="img"` with that name and hides its content from assistive technology, so initials are not read letter by letter.
- A group is `role="group"`; name it with `aria-label`.
- The initials use `muted-foreground` on `muted`, which meets 4.5:1 in both themes.
- Avatars are not interactive. Wrap one in a link or button yourself when it should be, and name that control.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | An avatar is not focusable and is skipped. |

## Theming

::component-tokens{component="avatar"}

The shape uses `--elf-radius-pill`: a circle in `elf`, a square in `novatron`.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Always provide a fallback for images that can fail. | Leave an empty circle while the image loads. |
| Use square images so `object-cover` does not distort faces. | Stretch non-square photos. |
| Limit a group to four or five avatars and add a `+N` avatar. | Show dozens of overlapping avatars. |
| Name the group or the avatar when there is no adjacent text. | Rely on initials alone to identify a person to a screen reader. |
