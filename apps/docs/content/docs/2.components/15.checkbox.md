## Usage

```vue
<script setup lang="ts">
const accepted = ref(false)
</script>

<template>
  <ElfCheckbox id="terms" v-model="accepted" />
  <ElfLabel for="terms">Accept the team code of conduct</ElfLabel>
</template>
```

`ElfCheckbox` is built on the Reka UI `Checkbox` primitive, which provides the `role="checkbox"` button, keyboard handling and the hidden form input. `v-model` is `boolean | 'indeterminate'`; use `default-value` for an uncontrolled checkbox, and `name` and `value` to submit it with a native form. Always pair it with a [Label](/docs/components/label) (put the checkbox first so `peer-disabled` dims the label) or an `aria-label`.

## Examples

### Indeterminate

`'indeterminate'` means "some, but not all". It renders a minus icon and `aria-checked="mixed"`. Clicking an indeterminate checkbox checks it. A parent checkbox derived from its children is the typical use.

::component-preview{name="checkbox-indeterminate"}

### With a description

Put the label and the helper text beside the checkbox and reference the text with `aria-describedby`.

::component-preview{name="checkbox-with-description"}

### In a Field

Inside [Field](/docs/components/field), wrap the checkbox in `ElfFieldControl` and place `ElfFieldLabel` next to it. The control receives `id`, `aria-describedby`, `aria-invalid` and the required state, and the label is bound to it. `ElfFieldError` is announced when it appears.

## Accessibility

- Follows the WAI-ARIA [Checkbox](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/) pattern: `role="checkbox"` with `aria-checked="true" | "false" | "mixed"`.
- The accessible name comes from a `<label for>` (or `aria-label`). A label also enlarges the click target.
- `invalid` (or a Field error) sets `aria-invalid="true"`; describe the problem in text and reference it with `aria-describedby`.
- Inside a Field with `required`, the checkbox gets `aria-required="true"`.
- The border uses the `input` token (3:1 against the background) and focus draws a ring in the `ring` token.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the checkbox. |
| <kbd>Space</kbd> | Toggles the checkbox (an indeterminate one becomes checked). |
| Click on the label | Toggles the checkbox. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Label every checkbox with visible text. | Rely on the box alone or on a tooltip. |
| Use a checkbox for choices that are submitted with a form. | Use a checkbox for settings that apply instantly; use Switch. |
| Use `indeterminate` only for a parent of partially selected children. | Set `indeterminate` on a lone checkbox. |
| Use a radio group when exactly one option may be chosen. | Use checkboxes for mutually exclusive options. |
