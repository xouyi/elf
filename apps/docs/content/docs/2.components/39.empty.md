## Usage

```vue
<ElfEmpty>
  <ElfEmptyHeader>
    <ElfEmptyMedia variant="icon"><FolderOpen /></ElfEmptyMedia>
    <ElfEmptyTitle>No projects yet</ElfEmptyTitle>
    <ElfEmptyDescription>Create one to start tracking tasks.</ElfEmptyDescription>
  </ElfEmptyHeader>
  <ElfEmptyContent>
    <ElfButton>Create project</ElfButton>
  </ElfEmptyContent>
</ElfEmpty>
```

`ElfEmpty` is composed from plain elements; there is no Reka UI primitive for it. It is a centered block with a dashed border that you place where the content would have been.

| Part | Purpose |
| :-- | :-- |
| `ElfEmpty` | The container. |
| `ElfEmptyHeader` | Groups media, title and description. |
| `ElfEmptyMedia` | An icon or illustration. `variant="icon"` puts the icon on a muted square. Decorative (`aria-hidden`). |
| `ElfEmptyTitle` | Heading, an `h3` by default. Change it with `as`. |
| `ElfEmptyDescription` | Muted explanation. |
| `ElfEmptyContent` | The action, for example a button. |

### Mobile

The block shrinks to the container width, the padding is smaller below `md` and the text wraps in a balanced way. Keep the action to one or two buttons so they wrap cleanly.

## Accessibility

- An empty state is static content with native semantics; there is no APG pattern and no keyboard interaction of its own. The action inside it is a normal button or link reached with <kbd>Tab</kbd>.
- The title is a real heading so screen reader users can find it. Choose the level with `as` to fit the page outline.
- The media is decorative and hidden from assistive technology; the title and description carry the meaning.
- If the empty state replaces content after a user action (for example a filter), consider moving the message into a live region so it is announced.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Say why it is empty and what to do next. | Show only "No data". |
| Offer the one action that fixes it. | Fill it with several competing actions. |
| Use a different message for "no results" than for "nothing created yet". | Reuse one empty state for every case. |
