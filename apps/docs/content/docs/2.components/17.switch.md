## Usage

```vue
<script setup lang="ts">
const reminders = ref(true)
</script>

<template>
  <ElfSwitch id="reminders" v-model="reminders" />
  <ElfLabel for="reminders">Match reminders</ElfLabel>
</template>
```

`ElfSwitch` is built on the Reka UI `Switch` primitive: a `role="switch"` button with a thumb that slides. `v-model` is a boolean; use `default-value` when uncontrolled and `name` to submit it with a native form. Give it a [Label](/docs/components/label) or an `aria-label`.

Use a switch for a setting whose change takes effect immediately, such as "Notifications on". For a choice that is submitted later with a form, use a [Checkbox](/docs/components/checkbox).

## Accessibility

- Follows the WAI-ARIA [Switch](https://www.w3.org/WAI/ARIA/apg/patterns/switch/) pattern: `role="switch"` with `aria-checked="true" | "false"`.
- The state is conveyed by the thumb position and a filled track in the `primary` token, not by color alone.
- The accessible name comes from a `<label for>` (or `aria-label`). Do not change the label text when the state changes.
- `aria-required` is not supported on `role="switch"`, so the switch does not offer a `required` state; use a checkbox when the user must opt in.
- The track border uses the `input` token (3:1 against the background). The thumb animation stops under `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the switch. |
| <kbd>Space</kbd> | Toggles the switch. |
| <kbd>Enter</kbd> | Toggles the switch. |
| Click on the label | Toggles the switch. |

The track and thumb use `--elf-radius-pill`: fully rounded in `elf`, square in `novatron`.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Apply the change as soon as the switch moves. | Make the user press Save for a switch. |
| Use a label that names the setting ("Notifications"). | Use a label that describes the action ("Turn on notifications"). |
| Disable the switch while the change is being saved, and say why if it stays disabled. | Hide a switch the user cannot change. |
| Use a checkbox for choices in a form. | Use a switch for several independent choices submitted together. |
