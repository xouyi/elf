## Usage

```vue
<script setup lang="ts">
const email = ref('')
</script>

<template>
  <label for="email" class="text-sm font-medium">Email</label>
  <ElfInput id="email" v-model="email" type="email" placeholder="you@example.com" />
</template>
```

## API Reference

::component-api{component="input"}

## Accessibility

- Always provide a visible `<label for>` or an `aria-label`; a placeholder is not a label.
- Set `aria-invalid="true"` for errors and describe the error in text next to the field.
- The border uses the `input` token, which is verified at 3:1 contrast against the page background.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the input. |
| Typing | Updates `v-model` on every input event. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use the right `type` (`email`, `number`, `password`). | Use `type="text"` for everything. |
| Show validation text next to the field. | Rely on the red border alone. |
| Use `ElfInput` for text entry. | Style a raw `<input>` with copied classes. |
