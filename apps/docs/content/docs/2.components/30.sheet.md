## Usage

```vue
<ElfSheet>
  <ElfSheetTrigger as-child><ElfButton variant="outline">Edit item</ElfButton></ElfSheetTrigger>
  <ElfSheetContent side="right">
    <ElfSheetHeader>
      <ElfSheetTitle>Edit item</ElfSheetTitle>
      <ElfSheetDescription>Change the name and quantity.</ElfSheetDescription>
    </ElfSheetHeader>
    <!-- form fields -->
    <ElfSheetFooter>
      <ElfSheetClose as-child><ElfButton variant="outline">Cancel</ElfButton></ElfSheetClose>
      <ElfButton>Save</ElfButton>
    </ElfSheetFooter>
  </ElfSheetContent>
</ElfSheet>
```

| Part | Notes |
| :-- | :-- |
| `ElfSheet` | Root. Props `open`, `defaultOpen`, `modal`. Emits `update:open`. |
| `ElfSheetTrigger` | Opens the sheet. Use `as-child` with a button. |
| `ElfSheetContent` | Portaled panel. Props `side`, `size`, `showCloseButton` (default `true`). |
| `ElfSheetHeader`, `ElfSheetTitle`, `ElfSheetDescription` | Heading structure. Title and description are required. |
| `ElfSheetFooter` | Action row pinned to the bottom of the panel. |
| `ElfSheetClose` | Closes the sheet. Use `as-child`. |

::callout{type="info" title="Sheet or dialog?"}
A sheet is a dialog docked to an edge. Use it for longer forms, filters and navigation, and for choices on a phone. Use `ElfAlertDialog` for confirmations.
::

## Examples

### Sides

`side` is `right` (default), `left`, `top` or `bottom`.

::component-preview{name="sheet-sides"}
::

### Bottom sheet

On a phone, `side="bottom"` spans the screen width, is capped at 85% of the viewport height, rounds its top corners and pads its bottom by `env(safe-area-inset-bottom)` so content stays above the home indicator.

::component-preview{name="sheet-bottom-sheet"}
::

### Sizes

`size` sets the maximum width of left and right sheets (`sm` 20rem, `default` 24rem, `lg` 36rem, `full` the whole viewport) and the maximum height of top and bottom sheets. Below the `sm` breakpoint left and right sheets always leave a 40px strip of the page visible.

## Accessibility

- Always include `ElfSheetTitle`; include `ElfSheetDescription` too (`class="sr-only"` hides it visually).
- Focus moves into the sheet on open, is trapped while it is open and returns to the trigger on close. The page behind is inert.
- A click on the backdrop closes the sheet. The close button is 40px on small screens.
- Slide animations stop under `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>Esc</kbd> | Closes the sheet and returns focus to the trigger. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Cycles through the focusable elements inside the sheet. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused button, including the trigger. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use a bottom sheet for short choices on a phone. | Put a long multi-step flow in a bottom sheet. |
| Keep the primary action in the footer. | Hide the only way to save in the scrolled content. |
| Pick the side that matches the trigger's position. | Open sheets from two edges at once. |
