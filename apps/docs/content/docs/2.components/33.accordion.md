## Usage

```vue
<ElfAccordion type="single" collapsible default-value="rules">
  <ElfAccordionItem value="rules">
    <ElfAccordionTrigger>Who can join?</ElfAccordionTrigger>
    <ElfAccordionContent>Any high-school student in Istanbul.</ElfAccordionContent>
  </ElfAccordionItem>
</ElfAccordion>
```

| Part | Notes |
| :-- | :-- |
| `ElfAccordion` | Root. `type` is `single` or `multiple`; `collapsible` lets the open item of a single accordion close; `v-model` holds a string (single) or a string array (multiple); `defaultValue`, `disabled`. |
| `ElfAccordionItem` | One section. Required `value`; optional `disabled`. |
| `ElfAccordionTrigger` | A button inside a heading (`h3`) with a rotating chevron. The `icon` slot replaces the chevron. |
| `ElfAccordionContent` | The region, animated like `ElfCollapsible`. |

## Accessibility

- Each trigger is a button in a heading; the content is a `region` labelled by its trigger.
- Disabled items are skipped by the arrow keys.
- The height animation and the chevron rotation stop under `prefers-reduced-motion`.
- The trigger is at least 40px high.

| Key | Action |
| :-- | :-- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Expands or collapses the focused section. |
| <kbd>↓</kbd> / <kbd>↑</kbd> | Moves focus to the next or previous trigger, wrapping around. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Moves focus to the first or last trigger. |
| <kbd>Tab</kbd> | Moves to the next focusable element, including links inside open sections. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use short, specific trigger labels. | Nest accordions. |
| Use `multiple` when users compare sections. | Hide content that most users need. |
