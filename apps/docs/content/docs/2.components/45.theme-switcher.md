## Usage

Set the themes up once ([Nuxt module options or `createElfTheme()`](/docs/getting-started/use-elf-theme#quick-start)), then drop the component anywhere:

```vue
<template>
  <ElfThemeSwitcher />
</template>
```

`ElfThemeSwitcher` calls [`useElfTheme()`](/docs/getting-started/use-elf-theme) itself, so it offers the configured themes, shows the active one, changes `data-theme` on `<html>` and remembers the choice (cookie or localStorage, as configured). It needs no `v-model`. Without any configuration it offers the shipped themes (`elf`, `nova`, `elfwood`) and does not persist.

`variant` picks the layout:

| Variant | Control | Use it for |
| :-- | :-- | :-- |
| `select` (default) | A [Select](/docs/components/select) | Many themes, or little room. |
| `buttons` | A segmented radio group | Two to four themes that should be visible at once. |
| `toggle` | One icon button that switches to the next theme | Headers and toolbars. |

Each theme is named after its theme name with a capital letter (`elfwood` becomes "Elfwood"). Rename them with `labels`. Custom themes work the same way: any name that `useElfTheme()` knows is listed, and its swatch uses the `primary` token of that theme.

## Accessibility

- `buttons` follows the WAI-ARIA [Radio Group](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) pattern: a `role="radiogroup"` named by `label`, with one `role="radio"` per theme and `aria-checked` on the active one. Only the checked radio is in the tab order.
- `select` is a Select-only combobox named by `label`; see [Select](/docs/components/select).
- `toggle` is a plain button. Its name includes the current theme, so the state is announced when it receives focus.
- The active theme is shown with a filled background and, in the select, a check mark, never by color alone. The swatch is decorative (`aria-hidden`).
- The theme only changes after a user action; the switcher never reads `prefers-color-scheme`.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus into the control (to the checked radio in `buttons`). |
| <kbd>ArrowRight</kbd> / <kbd>ArrowDown</kbd> | `buttons`: selects the next theme and wraps around. |
| <kbd>ArrowLeft</kbd> / <kbd>ArrowUp</kbd> | `buttons`: selects the previous theme and wraps around. |
| <kbd>Space</kbd> | `buttons`: selects the focused theme. `toggle`: switches to the next theme. |
| <kbd>Enter</kbd> | `toggle`: switches to the next theme. `select`: opens the list, then selects the highlighted theme. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | `select`: opens the list and moves the highlight. |
| <kbd>Escape</kbd> | `select`: closes the list. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Configure the themes once and use the switcher everywhere. | Pass a different `themes` list to every switcher in the app. |
| Use `buttons` for two to four themes and `select` for more. | Use `toggle` with many themes: the next one is hard to predict. |
| Rename themes with `labels` when their names mean nothing to users. | Hide the name of the active theme from assistive technology. |
