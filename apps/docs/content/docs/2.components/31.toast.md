## Usage

Mount one `ElfToaster` for the whole app, then call `useToast()` anywhere.

```vue
<!-- app.vue -->
<template>
  <NuxtPage />
  <ElfToaster position="bottom-right" :limit="3" />
</template>
```

```ts
const { toast } = useToast()

toast('Roster saved', { description: 'Visible to every member.' })
toast.success('Roster saved')
toast.warning('Battery 3 is low')
toast.error('Save failed')
toast.dismiss() // every toast, or toast.dismiss(id)
```

`toast()` returns the toast id. Showing a toast with an existing `id` updates it in place and restarts its timer; `toast.update(id, { message, variant, ... })` changes a visible toast.

| API | Notes |
| :-- | :-- |
| `toast(message, options)` | Options: `description`, `variant` (`default`, `success`, `warning`, `destructive`), `duration`, `action`, `id`, `onClose`. |
| `toast.success`, `toast.warning`, `toast.error` | Shortcuts for the variants (`error` is `destructive`). |
| `toast.promise(promise, { loading, success, error })` | A loading toast that becomes a success or destructive toast. Returns the promise (and rethrows rejections). |
| `toast.update(id, options)`, `toast.dismiss(id?)` | Change or close toasts. |
| `ElfToaster` props | `position`, `limit` (default 3), `duration` (default 5000), `label`, `announceLabel`, `hotkey` (default `F8`), `closeButton`, `closeLabel`. |

::callout{type="info" title="One toaster, a shared queue, safe on the server"}
`toast` is a module singleton that holds no per-request state, so calling it during server rendering is a harmless no-op. Toasts shown before the toaster mounts are replayed once it does. The examples on this site use the toaster mounted in the docs layout.
::

## Accessibility

- Every new toast is written into a persistent, visually hidden live region: `role="status"` (polite) for ordinary toasts and `role="alert"` (assertive) for `destructive` ones.
- Toasts do not take focus. Press <kbd>F8</kbd> to move focus to the notification region and <kbd>Tab</kbd> through the toasts.
- The timer pauses while the pointer is over the region, while focus is inside it and while the window is blurred.
- Do not put information that is only available in a toast; important results belong on the page as well (see Alert).
- The dismiss button and the action are 40px high on small screens; the stack spans the width and respects the safe area.
- Animations stop under `prefers-reduced-motion`.

| Key | Action |
| :-- | :-- |
| <kbd>F8</kbd> | Moves focus to the notification region. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | Moves between toasts, their actions and close buttons. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused action or close button. |
| <kbd>Esc</kbd> | Closes the focused toast. |
| Swipe | Swipe towards the screen edge to dismiss (right for right-hand positions, left, up or down otherwise). |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Confirm a finished action briefly. | Show errors that need a decision; use a dialog or an Alert. |
| Offer Undo with an action. | Rely on a toast being read before it closes. |
| Keep messages to one short sentence. | Stack more than a few toasts. |
