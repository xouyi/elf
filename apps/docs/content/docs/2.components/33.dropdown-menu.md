## Usage

```vue
<template>
  <ElfDropdownMenu>
    <ElfDropdownMenuTrigger as-child>
      <ElfButton variant="outline">My account</ElfButton>
    </ElfDropdownMenuTrigger>
    <ElfDropdownMenuContent align="start">
      <ElfDropdownMenuLabel>Signed in as ayse</ElfDropdownMenuLabel>
      <ElfDropdownMenuItem>Profile</ElfDropdownMenuItem>
      <ElfDropdownMenuSeparator />
      <ElfDropdownMenuItem variant="destructive">Sign out</ElfDropdownMenuItem>
    </ElfDropdownMenuContent>
  </ElfDropdownMenu>
</template>
```

`ElfDropdownMenu` is built on the Reka UI `DropdownMenu` primitive, which provides the menu button pattern: roving focus, typeahead, sub menus, dismissal, collision handling and the ARIA wiring. The parts are:

| Part | Purpose |
| :-- | :-- |
| `ElfDropdownMenu` | Holds the open state (`v-model:open`) and `modal`. Renders no element. |
| `ElfDropdownMenuTrigger` | The button that opens the menu. Use `as-child` to wrap your own button; icon-only triggers need an `aria-label`. |
| `ElfDropdownMenuContent` | The menu, rendered in a portal. `side`, `align`, `sideOffset`. |
| `ElfDropdownMenuItem` | An action. Emits `select`. `variant="destructive"` for irreversible actions, `inset` to align with indicator items, `disabled`. |
| `ElfDropdownMenuCheckboxItem` | A toggle bound with `v-model`. |
| `ElfDropdownMenuRadioGroup`, `ElfDropdownMenuRadioItem` | One choice from several, bound with `v-model` on the group. |
| `ElfDropdownMenuLabel`, `ElfDropdownMenuGroup`, `ElfDropdownMenuSeparator` | Name and divide groups of items. |
| `ElfDropdownMenuSub`, `ElfDropdownMenuSubTrigger`, `ElfDropdownMenuSubContent` | A nested menu. |
| `ElfDropdownMenuShortcut` | Right-aligned shortcut hint. Put [`ElfKbd`](/docs/components/kbd) elements inside; it is a hint only, you bind the keys yourself. |

The styles are shared with [Context Menu](/docs/components/context-menu) through `menuContentClass`, `menuItemVariants`, `menuLabelClass`, `menuSeparatorClass` and `menuShortcutClass`.

### Mobile

Item rows are 40px high below the `md` breakpoint and use 16px text; the menu never exceeds the available viewport height and scrolls inside it. Open it with a tap on the trigger.

## Accessibility

- Follows the WAI-ARIA [Menu Button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) pattern: the trigger has `aria-haspopup="menu"` and `aria-expanded`; the popup has `role="menu"` and its rows are `menuitem`, `menuitemcheckbox` or `menuitemradio` with `aria-checked`.
- Focus moves into the menu when it opens and returns to the trigger when it closes. Disabled items are exposed with `aria-disabled` and skipped by typeahead.
- Selection state is shown by an indicator, never by colour alone; the destructive item uses a readable text token, and the label must say what it does ("Delete"), not just look red.
- While a menu is open the page behind it is hidden from assistive technology and inert (`modal`).
- Menus are for actions and commands. Use a [Select](/docs/components/select) to choose a value for a form field.

| Key | Action |
| :-- | :-- |
| <kbd>Enter</kbd> / <kbd>Space</kbd> / <kbd>ArrowDown</kbd> | On the trigger, opens the menu and focuses the first item. |
| <kbd>ArrowUp</kbd> | On the trigger, opens the menu and focuses the last item. |
| <kbd>ArrowDown</kbd> / <kbd>ArrowUp</kbd> | Moves to the next or previous item. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Focuses the first or last item. |
| Typing | Typeahead: focuses the next item whose text starts with the typed characters. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the item (toggles checkbox items, selects radio items) and closes the menu. |
| <kbd>ArrowRight</kbd> | On a sub menu trigger, opens the sub menu (<kbd>ArrowLeft</kbd> in right-to-left layouts). |
| <kbd>ArrowLeft</kbd> | In a sub menu, closes it and returns to its trigger. |
| <kbd>Escape</kbd> | Closes the menu (or the sub menu) and returns focus to the trigger. |
| <kbd>Tab</kbd> | Closes the menu. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Group related items and separate dangerous ones at the end. | List dozens of items without groups. |
| Use `variant="destructive"` for delete and similar, and confirm important ones with a dialog. | Rely on colour only to signal danger. |
| Give an icon-only trigger an `aria-label`. | Put form inputs or long content in a menu; use a popover. |
| Use a Select for choosing a field value. | Use a menu to pick a value that belongs in a form. |
