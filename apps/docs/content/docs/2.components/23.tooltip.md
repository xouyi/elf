## Usage

```vue
<template>
  <ElfTooltip>
    <ElfTooltipTrigger as-child>
      <ElfButton variant="outline">Hover or focus me</ElfButton>
    </ElfTooltipTrigger>
    <ElfTooltipContent>Saved to your team library</ElfTooltipContent>
  </ElfTooltip>
</template>
```

`ElfTooltip` is built on the Reka UI `Tooltip` primitive, which provides hover and focus opening, the open delay, dismissal, collision handling and the ARIA wiring. The parts are:

| Part | Purpose |
| :-- | :-- |
| `ElfTooltipProvider` | Optional. Shares the open delay between tooltips and lets a neighbour open instantly right after another closes. Put one near the app root or around a toolbar. |
| `ElfTooltip` | Holds the open state (`v-model:open`). Renders no element. Creates its own provider when none is above it. |
| `ElfTooltipTrigger` | The element that is described. Renders a `button` by default; use `as-child` to wrap your own button or link. |
| `ElfTooltipContent` | The hint, rendered in a portal. Accepts `side`, `align`, `sideOffset` and the other Reka content props. |

Keep the content to a short phrase of plain text. A tooltip cannot hold links, buttons or anything the user must reach: use a [Popover](/docs/components/popover) for that.

### Mobile

Tooltips are a pointer and keyboard feature. Touch screens have no hover, so a tooltip never opens on a tap: do not hide information that touch users need behind one. Icon-only buttons still need an `aria-label`, which is what touch and screen reader users get.

## Accessibility

- Follows the WAI-ARIA [Tooltip](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/) pattern: the floating element has `role="tooltip"` and the trigger points at it with `aria-describedby` while it is open.
- The tooltip describes its trigger, it does not name it. Give the trigger its own accessible name (visible text or `aria-label`).
- It opens on keyboard focus as well as on hover, closes on Escape without moving focus, and stays open while the pointer moves onto the hint itself (WCAG 1.4.13: dismissible, hoverable, persistent).
- Content is never the only way to reach information, and it holds no interactive elements.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the trigger and opens the tooltip. |
| <kbd>Escape</kbd> | Closes the tooltip. Focus stays on the trigger. |
| <kbd>Shift</kbd> + <kbd>Tab</kbd> / <kbd>Tab</kbd> | Moving focus away closes the tooltip. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use it to name or explain an icon-only control, or to show a shortcut. | Put essential information, links or buttons in it. |
| Keep it to a few words of plain text. | Write paragraphs; use a popover or visible help text. |
| Wrap related controls in one `ElfTooltipProvider`. | Rely on it for touch users, who cannot hover. |
