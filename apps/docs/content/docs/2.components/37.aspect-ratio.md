## Usage

The frame fills the width of its parent and takes its height from `ratio` (width divided by height). Constrain the width on the parent.

```vue
<div class="w-full max-w-sm">
  <ElfAspectRatio :ratio="16 / 9">
    <img src="/cover.jpg" alt="Robot on the field">
  </ElfAspectRatio>
</div>
```

An `img` or `video` child is sized to the frame and cropped to cover it. Any other content fills the frame as a block.

## Accessibility

The frame is presentational and is not focusable, so it has no keyboard interaction. Give an `img` an `alt`. A placeholder that stands in for an image should have `role="img"` and an `aria-label`; decorative content should be hidden with `aria-hidden`.

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use the same ratio for every card in a grid. | Mix ratios in one row of thumbnails. |
| Reserve space before media loads. | Rely on the image's own size to set the height. |
| Constrain the width on the parent. | Put the frame in a parent with no width. |
