## Usage

```vue
<script setup lang="ts">
const notes = ref('')
</script>

<template>
  <ElfLabel for="notes">Notes</ElfLabel>
  <ElfTextarea id="notes" v-model="notes" auto-resize :rows="2" class="max-h-48" />
</template>
```

Reka UI has no textarea primitive, so `ElfTextarea` composes the native element. It shares the `ElfInput` border, focus ring and invalid styles; unlike `ElfInput` it has no size scale because its height comes from `rows`.

## Examples

### Auto resize

With `auto-resize` the height follows the content, including when the width changes and the text rewraps. `rows` becomes the minimum. Add a `max-h-*` class to cap growth; the textarea scrolls beyond it, and the manual resize handle is hidden.

::component-preview{name="textarea-auto-resize"}
::

### Invalid

`invalid` sets `aria-invalid="true"` and the destructive border and ring. Describe the error in text and link it with `aria-describedby`; [Field](/docs/components/field) does this for you.

## Accessibility

- Always provide a visible `<label for>` (see [Label](/docs/components/label), or [Field](/docs/components/field) for the whole row) or an `aria-label`; a placeholder is not a label.
- `invalid` sets `aria-invalid="true"`. Describe the error in text next to the field and reference it with `aria-describedby`.
- Pressing <kbd>Enter</kbd> inserts a new line; it never submits a form.
- The border uses the `input` token, which is verified at 3:1 contrast against the page background.
- Auto-resize only changes the height; it does not move focus or the caret.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus to the textarea (and away from it; Tab does not insert a tab character). |
| <kbd>Enter</kbd> | Inserts a new line. |
| Typing | Updates `v-model` on every input event. |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use `auto-resize` with a `max-h-*` class for open-ended text. | Let an auto-resizing textarea grow without a cap. |
| Use `maxlength` and show the count to the user. | Truncate the input silently on the server. |
| Show validation text next to the field. | Rely on the red border alone. |
