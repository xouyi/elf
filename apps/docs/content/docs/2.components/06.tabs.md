## Usage

```vue
<ElfTabs default-value="overview">
  <ElfTabsList aria-label="Account sections">
    <ElfTabsTrigger value="overview">Overview</ElfTabsTrigger>
    <ElfTabsTrigger value="settings">Settings</ElfTabsTrigger>
  </ElfTabsList>
  <ElfTabsContent value="overview">...</ElfTabsContent>
  <ElfTabsContent value="settings">...</ElfTabsContent>
</ElfTabs>
```

## Examples

### Controlled with manual activation

Control the selection with `v-model`. With `activation-mode="manual"` the arrow keys move focus and Enter or Space selects, which suits heavy panels. A trigger can be `disabled`.

## Accessibility

Implements the WAI-ARIA tabs pattern. Label the list with `aria-label` or `aria-labelledby`.

| Key | Action |
| :-- | :-- |
| <kbd>Tab</kbd> | Moves focus into the tab list, then into the active panel. |
| <kbd>Left</kbd> / <kbd>Right</kbd> | Moves to the previous or next tab (`orientation="horizontal"`). |
| <kbd>Up</kbd> / <kbd>Down</kbd> | Moves between tabs when `orientation="vertical"`. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Moves to the first or last tab. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | Activates the focused tab (with `activation-mode="manual"`). |

## Do and don't

| Do | Don't |
| :-- | :-- |
| Use short, noun-based labels. | Use more than five or six tabs. |
| Use tabs for peer views of the same data. | Use tabs for a step-by-step flow. |
| Keep panel content independent. | Hide required form fields in inactive tabs. |
