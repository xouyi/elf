A theme is a set of CSS variables prefixed with `--elf-`, declared under `[data-theme='<name>']`. Components never hard-code colors: they use Tailwind utilities (`bg-primary`, `border-border`) that resolve to these variables.

## Themes

| Theme | Character | Radius | Primary |
| :-- | :-- | :-- | :-- |
| `elf` (default) | Pure black, neutral grey surfaces with violet brand accents | `0.625rem` rounded | violet `#a388f8` |
| `nova` | Obsidian black with gold, built for Novatron Robotics apps | `0` sharp corners | gold `#ffcc00` |
| `elfwood` | Light: white and near-white surfaces with deep forest green | `0.5rem` rounded | green `#15803d` |

`elf` and `nova` are dark themes. `elfwood` is the first light theme: it sets `color-scheme: light` so form controls and scrollbars follow. Components use tokens only, so never add `dark:` variants or hard-coded colors. Use the switcher in the header to flip this whole site between the themes.

## Switching themes

```ts
document.documentElement.dataset.theme = 'elf' // or 'nova', 'elfwood'
```

To read or change the theme from code, with persistence and server-side rendering support, use [`useElfTheme()`](/docs/getting-started/use-elf-theme).

With the Nuxt module the initial theme is the `elfui.theme` option. Bundle every theme you switch to with `elfui.themes`. Tokens can also be scoped to any element:

```html
<section data-theme="elf">This subtree uses the elf theme.</section>
```

### What each token is for

| Token | Tailwind utility | Purpose |
| :-- | :-- | :-- |
| `--elf-background` / `-foreground` | `bg-background` `text-foreground` | Page surface and default text |
| `--elf-card` / `-card-foreground` | `bg-card` | Cards and panels |
| `--elf-popover` / `-popover-foreground` | `bg-popover` | Dialogs and floating surfaces |
| `--elf-primary` / `-primary-foreground` | `bg-primary` | Main actions and emphasis |
| `--elf-secondary` / `-secondary-foreground` | `bg-secondary` | Secondary actions |
| `--elf-muted` / `-muted-foreground` | `bg-muted` `text-muted-foreground` | Subtle surfaces, helper text |
| `--elf-accent` / `-accent-foreground` | `bg-accent` | Hover and selected states |
| `--elf-destructive` / `-destructive-foreground` | `bg-destructive` | Dangerous actions and errors (a fill) |
| `--elf-destructive-text` | `text-destructive-text` | Readable error text and required markers on `background`, `card` and `popover` (4.5:1) |
| `--elf-success` / `-success-foreground` | `bg-success` | Positive status |
| `--elf-warning` / `-warning-foreground` | `bg-warning` | Cautionary status |
| `--elf-success-text` | `text-success-text` | Readable success text and icons on `background`, `card` and `popover` (4.5:1) |
| `--elf-warning-text` | `text-warning-text` | Readable warning text and icons on `background`, `card` and `popover` (4.5:1) |
| `--elf-border` | `border-border` | Borders and dividers |
| `--elf-input` | `border-input` | Form control borders (3:1 contrast) |
| `--elf-ring` | `ring-ring` | Focus ring (3:1 contrast) |
| `--elf-radius` | `rounded-lg` and friends | Base corner radius |
| `--elf-radius-pill` | `rounded-badge` | Badge radius |

## Create your theme

1. Create a CSS file (in this repository `src/themes/<name>.css`) and define every token:

   ```css
   [data-theme='ocean'] {
     --elf-background: oklch(0.14 0.02 240);
     --elf-foreground: oklch(0.97 0.005 240);
     /* ...every token from the table above, with -foreground pairs... */
     --elf-radius: 0.5rem;
     --elf-radius-pill: 9999px;
   }
   ```

2. Import it after `@import '@xouyi/elfui/styles.css'`.
3. Set `data-theme="ocean"`.
4. In this repository, add the name to `elfThemes` in `src/index.ts` and run `bun run contrast`. It checks WCAG AA: 4.5:1 for text pairs and 3:1 for the input border and focus ring. This page's contrast table is produced by the same code, so a new theme file appears here on the next build.

::callout{type="tip" title="Pick colors by contrast first"}
Choose the background and foreground pair, then the primary and its foreground, and run `bun run contrast` after each step. Muted text on cards is the pair that most often fails.
::

## Elf, Nova and Elfwood

Use **elf** for general products and **elfwood** when you want a light, green-and-white interface. Use **nova** for anything representing Novatron Robotics (FRC Team 10202): obsidian `#050505` background, gold `#ffcc00` primary, and `0` radius everywhere. Under nova, rounded utilities such as `rounded-md` resolve to `0` because they derive from `--elf-radius`, so never override radii with arbitrary values.
