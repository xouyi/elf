---
title: CLI-less usage
description: Use ElfUI without the shadcn-vue CLI, by copying component sources by hand or installing only the package.
---

You do not need the shadcn-vue CLI. There are two CLI-free ways to use ElfUI.

## Install the package

The [Nuxt](/docs/getting-started/installation-nuxt) and [Vite + Vue](/docs/getting-started/installation-vite) guides use plain `bun add`. Nothing else has to be installed or configured globally.

## Copy the sources by hand

Every component is a folder of `.vue` and `.ts` files in [`src/components`](https://github.com/xouyi/elfUI/tree/main/src/components). To fork one without any tooling:

1. Copy the component folder (for example `button/`) into your project, e.g. `components/ui/button/`.
2. Copy `src/lib/utils.ts` (the `cn()` helper) to `lib/utils.ts` and install its dependencies:

   ```bash
   bun add clsx tailwind-merge class-variance-authority reka-ui @vueuse/core
   ```

3. In the copied files, replace the relative imports (`../../lib/utils`, `../button`) with your own aliases or paths.
4. Copy `src/styles.css` and the theme files from `src/themes/`, and import them after `@import 'tailwindcss'`.

The registry JSON files do exactly this for you, and you can read them directly: each file under `/r/<name>.json` lists the file contents with the rewritten imports.

::callout{type="info"}
Skip the `examples/` folders and `*.test.ts` files when copying. They are documentation and tests, not part of a component.
::
