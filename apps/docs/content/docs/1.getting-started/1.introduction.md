ElfUI is a set of accessible components for **Vue 3 and Nuxt 4**. Components are built on [Reka UI](https://reka-ui.com) primitives, follow the [shadcn-vue](https://www.shadcn-vue.com) structure (CVA variants, `cn()`, CSS-variable theming) and are styled with **Tailwind CSS v4**.

::component-preview{name="card-default"}
::

## Why ElfUI

- **Accessible by default.** Reka UI handles focus management, keyboard interaction and ARIA. Every example is verified with axe in every theme, and `bun run contrast` verifies WCAG AA contrast for every theme.
- **Themeable with one file.** A theme is a block of `--elf-*` CSS variables selected with `data-theme`. Three ship today: `elf` (pure black with violet accents, rounded), `nova` (gold on obsidian, sharp corners) and `elfwood` (light, green on white).
- **Dark first, one light theme.** `elf` and `nova` are dark; `elfwood` is light. Components use tokens only, so every surface, border and focus ring follows the active theme.
- **Source distributed.** You install Vue SFC sources, so your bundler, Tailwind and TypeScript see exactly what runs. Install `@xouyi/elfui` from npm, or prefer to own the code? [Copy components](/docs/getting-started/registry) into your project with `bunx @xouyi/elfui add`.
- **Built for humans and AI assistants.** A machine-readable [`llms.txt`](/docs/resources/for-ai) describes every component, prop and rule.

## What is included

| Area | Contents |
| :-- | :-- |
| Package | `bun add @xouyi/elfui` (npm). |
| Components | Button, Input, Textarea, Label, Field, Checkbox, Radio Group, Switch, Select, Badge, Alert, Progress, Avatar, Card, Skeleton, Spinner, Separator, Kbd, Visually Hidden, Tabs, Dialog, Alert Dialog, Sheet, Tooltip, Popover, Hover Card, Dropdown Menu, Context Menu, Scroll Area, Toaster (`useToast`), Collapsible, Accordion and Gradient Text. Vue components carry the `Elf` prefix, for example `ElfButton`. |
| Themes | `elf`, `nova` and `elfwood`, switched at runtime with `data-theme` on any element. |
| Nuxt module | `@xouyi/elfui/nuxt` auto-imports components and injects theme tokens. |
| CLI | `bunx @xouyi/elfui@latest init` sets up a project, `bunx @xouyi/elfui add button` copies components. |
| Registry | A shadcn-vue compatible registry served at `https://xouyi.github.io/elfUI/r/{name}.json`. |

## How this site is built

This documentation is a Nuxt 4 app that uses ElfUI for its own interface. The previews are the real components, the code tabs show the exact example files that the tests render, and the API tables are generated from the component sources at build time, so they cannot drift.
