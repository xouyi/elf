ElfUI is a set of accessible components for **Vue 3 and Nuxt 4**. Components are built on [Reka UI](https://reka-ui.com) primitives, follow the [shadcn-vue](https://www.shadcn-vue.com) structure (CVA variants, `cn()`, CSS-variable theming) and are styled with **Tailwind CSS v4**.

::component-preview{name="card-default"}
::

## Why ElfUI

- **Accessible by default.** Reka UI handles focus management, keyboard interaction and ARIA. Every example is verified with axe in both themes, and `bun run contrast` verifies WCAG AA contrast for every theme.
- **Themeable with one file.** A theme is a block of `--elf-*` CSS variables selected with `data-theme`. Two ship today: `elf` (violet, rounded) and `novatron` (gold on obsidian, sharp corners).
- **Dark only.** There is no light mode to maintain. Every surface, border and focus ring is tuned for dark.
- **Source distributed.** You install Vue SFC sources, so your bundler, Tailwind and TypeScript see exactly what runs. Prefer to own the code? [Copy components](/docs/getting-started/registry) into your project with the shadcn-vue registry.
- **Built for humans and AI assistants.** A machine-readable [`llms.txt`](/docs/resources/for-ai) describes every component, prop and rule.

## What is included

| Area | Contents |
| :-- | :-- |
| Components | Button, Input, Badge, Card, Dialog, Tabs. Vue components carry the `Elf` prefix, for example `ElfButton`. |
| Themes | `elf` and `novatron`, switched at runtime with `data-theme` on any element. |
| Nuxt module | `@elf/ui/nuxt` auto-imports components and injects theme tokens. |
| Registry | A shadcn-vue registry served at `https://xouyi.github.io/elfUI/r/{name}.json`. |

## How this site is built

This documentation is a Nuxt 4 app that uses ElfUI for its own interface. The previews are the real components, the code tabs show the exact example files that the tests render, and the API tables are generated from the component sources at build time, so they cannot drift.
