title: Registry
description: Copy ElfUI components into your project with the shadcn-vue CLI and fork them freely.
---

Prefer to own the code? The [shadcn-vue](https://www.shadcn-vue.com) CLI can copy ElfUI components into your project so you can fork them freely. Imports are rewritten to your own aliases (`@/lib/utils`, `@/components/ui/*`).

## Add a single component

```bash
bunx shadcn-vue@latest add https://xouyi.github.io/elfUI/r/button.json
```

Dependencies such as `utils` are installed automatically through `registryDependencies`.

## Register the namespace

Add this to your `components.json`, then use short names:

```json [components.json]
{
  "registries": {
    "@elf": "https://xouyi.github.io/elfUI/r/{name}.json"
  }
}
```

```bash
bunx shadcn-vue@latest add @elf/button @elf/dialog @elf/elf-theme
```

## Available items

| Item | Description |
| :-- | :-- |
| `utils` | `cn()` helper (clsx and tailwind-merge) |
| `button`, `input`, `badge`, `card`, `dialog`, `tabs` | Components |
| `elf-theme` | Tailwind v4 token mapping and the `elf` and `novatron` theme files |

The full index is served at [`/r/registry.json`](https://xouyi.github.io/elfUI/r/registry.json).

## Fallback host

If GitHub Pages is unavailable, the same files are served from the repository:

```text
https://raw.githubusercontent.com/xouyi/elfUI/main/registry/r/{name}.json
```

Items fetched from the fallback still list the Pages URL in their `registryDependencies`.

## Package or registry?

| | Package (`elfui`) | Registry |
| :-- | :-- | :-- |
| Updates | Bump the tag | Re-run `add` and merge |
| Customization | Props, classes, tokens | Edit the source |
| Best for | Following the design system | Heavily customized apps |
