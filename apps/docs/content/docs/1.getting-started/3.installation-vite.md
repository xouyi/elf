---
title: Installation (Vite + Vue)
description: Use ElfUI in a plain Vue 3 app built with Vite, without Nuxt.
---

ElfUI is published on npm as [`@xouyi/elfui`](https://www.npmjs.com/package/@xouyi/elfui) and works in any Vue 3 app built with Vite. The Nuxt module only automates component registration, theme CSS and the `data-theme` attribute, so you do those three things yourself.

## Quick start (CLI)

In an existing Vite + Vue project:

```bash
bunx @xouyi/elfui@latest init
```

`init` installs `@xouyi/elfui`, `tailwindcss`, `@tailwindcss/vite` and `typescript@5` (when missing) with Bun, adds `tailwindcss()` to `vite.config.ts`, and puts the Tailwind, ElfUI and theme imports into your main CSS file (creating `src/style.css` when there is none). It is safe to run again, and when it does not recognize your config it changes nothing and prints the manual steps. See the [CLI page](/docs/getting-started/cli).

Prefer to do it by hand? The steps below are exactly what `init` does.

## 1. Install

::install-command{extra="tailwindcss @tailwindcss/vite"}
::

```bash
bun add -d typescript@5 vite @vitejs/plugin-vue
```

::callout{type="warning" title="Use TypeScript 5 or 6"}
`bun add -d typescript` installs TypeScript 7, the native port, which no longer exposes the JavaScript API the Vue compiler uses. The build then fails with "No fs option provided to `compileScript`". Pin `typescript@5`.
::

## 2. Vite config

```ts [vite.config.ts]
import tailwindcss from '@tailwindcss/vite'
import vue from '@vitejs/plugin-vue'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [vue(), tailwindcss()],
})
```

ElfUI ships `.vue` and `.ts` sources. Vite compiles them like your own code, so no extra transpile step is needed.

## 3. Styles and theme

```css [src/style.css]
@import 'tailwindcss';
@import '@xouyi/elfui/styles.css';
@import '@xouyi/elfui/themes/elf.css';
@import '@xouyi/elfui/themes/nova.css';
```

```html [index.html]
<html lang="en" data-theme="elf">
```

## 4. Import components

```vue
<script setup lang="ts">
import { ElfButton, ElfCard, ElfCardContent } from '@xouyi/elfui'
</script>

<template>
  <ElfCard>
    <ElfCardContent><ElfButton>Save</ElfButton></ElfCardContent>
  </ElfCard>
</template>
```

Types and helpers are exported too: `ButtonProps`, `BadgeProps`, `ButtonVariants`, `BadgeVariants`, `cn`, `buttonVariants`, `badgeVariants`, `elfThemes` and `ElfTheme`.

## Switching themes

```ts
document.documentElement.dataset.theme = 'nova'
```

Tokens are scoped to `[data-theme]`, so a single element can use a different theme from the page: `<div data-theme="elf">...</div>`.
