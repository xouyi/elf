ElfUI is published on npm as [`{{pkg}}`]({{npm}}). It requires **Bun**, **Nuxt 4**, **Tailwind CSS v4** and **TypeScript**.

## Quick start (CLI)

In an existing Nuxt 4 project:

```bash
bunx {{pkg}}@latest init
```

`init` installs `{{pkg}}`, `tailwindcss`, `@tailwindcss/vite` and `typescript@5` (when missing) with Bun, registers the module, adds the Tailwind Vite plugin to `nuxt.config.ts` and creates or patches your main CSS. It is safe to run again. Add `--theme nova --yes` to skip the prompts. See the [CLI page](/docs/getting-started/cli) for every option.

Prefer to do it by hand? The steps below are exactly what `init` does.

## 1. Install

::install-command{extra="tailwindcss @tailwindcss/vite"}
::

```bash
bun add -d typescript@5
```

::callout{type="info" title="Why TypeScript?"}
The Vue compiler uses the `typescript` package to resolve the Reka UI prop types inside ElfUI's single-file component sources. Install **TypeScript 5 or 6**: TypeScript 7 is the native port and no longer exposes the JavaScript API the Vue compiler needs, so builds fail with "No fs option provided to `compileScript`".
::

## 2. Configure Nuxt

```ts [nuxt.config.ts]
import tailwindcss from '@tailwindcss/vite'

export default defineNuxtConfig({
  modules: ['{{pkg}}/nuxt'],
  css: ['~/assets/css/main.css'],
  elfui: { theme: 'nova', themes: ['elf'] }, // config key stays `elfui` (the module is `{{pkg}}/nuxt`); 'elf' | 'nova' | 'elfwood'
  vite: { plugins: [tailwindcss()] },
})
```

The module registers every component with the `Elf` prefix, adds the token CSS of the selected theme and sets `data-theme` on `<html>`. Themes listed in `themes` are bundled and available for runtime switching: call `useElfTheme()` with no arguments (see [Switching themes](#switching-themes)).

## 3. Add the Tailwind v4 entry

```css [app/assets/css/main.css]
@import 'tailwindcss';
@import '{{pkg}}/styles.css';
```

`{{pkg}}/styles.css` maps ElfUI tokens to Tailwind colors (`bg-primary`, `text-muted-foreground`, ...) and radii, and tells Tailwind to scan the ElfUI component sources. Import it **after** Tailwind.

## 4. Use a component

```vue [app/pages/index.vue]
<template>
  <ElfCard>
    <ElfCardHeader>
      <ElfCardTitle>Hello ElfUI</ElfCardTitle>
      <ElfCardDescription>Components are auto-imported.</ElfCardDescription>
    </ElfCardHeader>
    <ElfCardContent>
      <ElfButton>Save</ElfButton>
    </ElfCardContent>
  </ElfCard>
</template>
```

## Switching themes

The theme choice is remembered in a cookie that the server reads, so the page renders with the right theme from the first byte. No further setup:

```vue
<script setup lang="ts">
const { theme, toggle } = useElfTheme()
</script>

<template>
  <ElfButton variant="outline" @click="toggle">Theme: {{ theme }}</ElfButton>
</template>
```

See [useElfTheme](/docs/getting-started/use-elf-theme) for the full API.

## Module options

| Option | Type | Default | Description |
| :-- | :-- | :-- | :-- |
| `theme` | `'elf' \| 'nova' \| 'elfwood'` | `'elf'` | Theme applied through `data-theme` on `<html>`. |
| `themes` | `ElfTheme[]` | selected theme only | Extra themes to bundle and to switch between with `useElfTheme()`. |
| `persist` | `'cookie' \| 'localStorage' \| false` | `'cookie'` | Where the visitor's theme choice is kept. |
| `prefix` | `string` | `'Elf'` | Component name prefix. |

## Upgrading

```bash
bun update {{pkg}}
```

Pin an exact version with `bun add {{pkg}}@{{version}}`. Release notes are in the [changelog](/docs/resources/changelog). To install an unreleased commit instead, see [Install from GitHub](/docs/getting-started/github-install).
