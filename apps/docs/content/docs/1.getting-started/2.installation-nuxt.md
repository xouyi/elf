ElfUI is published on npm as [`elfui`](https://www.npmjs.com/package/elfui). It requires **Bun**, **Nuxt 4**, **Tailwind CSS v4** and **TypeScript**.

## Quick start (CLI)

In an existing Nuxt 4 project:

```bash
bunx elfui@latest init
```

`init` installs `elfui`, `tailwindcss`, `@tailwindcss/vite` and `typescript@5` (when missing) with Bun, registers the module, adds the Tailwind Vite plugin to `nuxt.config.ts` and creates or patches your main CSS. It is safe to run again. Add `--theme novatron --yes` to skip the prompts. See the [CLI page](/docs/getting-started/cli) for every option.

Prefer to do it by hand? The steps below are exactly what `init` does.

## 1. Install

::install-command{extra="tailwindcss @tailwindcss/vite"}
::

```bash
bun add -d typescript@5
```

::callout{type="info" title="Why TypeScript?"}
The Vue compiler uses the `typescript` package to resolve the Reka UI prop types inside ElfUI's single-file component sources. Install **TypeScript 5 or 6**: TypeScript 7 is the native port and no longer exposes the JavaScript API the Vue compiler needs, so builds fail with "No fs option provided to `compileScript`".
::

## 2. Configure Nuxt

```ts [nuxt.config.ts]
import tailwindcss from '@tailwindcss/vite'

export default defineNuxtConfig({
  modules: ['elfui/nuxt'],
  css: ['~/assets/css/main.css'],
  elfui: { theme: 'novatron' }, // 'elf' | 'novatron'
  vite: { plugins: [tailwindcss()] },
})
```

The module registers every component with the `Elf` prefix, adds the token CSS of the selected theme and sets `data-theme` on `<html>`. To bundle more themes for runtime switching, list them: `elfui: { theme: 'novatron', themes: ['elf'] }`.

## 3. Add the Tailwind v4 entry

```css [app/assets/css/main.css]
@import 'tailwindcss';
@import 'elfui/styles.css';
```

`elfui/styles.css` maps ElfUI tokens to Tailwind colors (`bg-primary`, `text-muted-foreground`, ...) and radii, and tells Tailwind to scan the ElfUI component sources. Import it **after** Tailwind.

## 4. Use a component

```vue [app/pages/index.vue]
<template>
  <ElfCard>
    <ElfCardHeader>
      <ElfCardTitle>Hello ElfUI</ElfCardTitle>
      <ElfCardDescription>Components are auto-imported.</ElfCardDescription>
    </ElfCardHeader>
    <ElfCardContent>
      <ElfButton>Save</ElfButton>
    </ElfCardContent>
  </ElfCard>
</template>
```

## Module options

| Option | Type | Default | Description |
| :-- | :-- | :-- | :-- |
| `theme` | `'elf' \| 'novatron'` | `'elf'` | Theme applied through `data-theme` on `<html>`. |
| `themes` | `ElfTheme[]` | selected theme only | Extra theme token files to bundle. |
| `prefix` | `string` | `'Elf'` | Component name prefix. |

## Upgrading

```bash
bun update elfui
```

Pin an exact version with `bun add elfui@0.3.0`. Release notes are in the [changelog](/docs/resources/changelog). To install an unreleased commit instead, see [Install from GitHub](/docs/getting-started/github-install).

## Try the example

The repository contains a complete Nuxt 4 app that consumes ElfUI like a real project: [`examples/nuxt-demo`](https://github.com/xouyi/elfUI/tree/main/examples/nuxt-demo). Its build runs in CI on every change, so these steps are tested against a real install.
