title: Installation (Nuxt)
description: Install ElfUI in a Nuxt 4 app with Bun, Tailwind CSS v4 and the ElfUI Nuxt module.
---

ElfUI requires **Bun**, **Nuxt 4**, **Tailwind CSS v4** and **TypeScript**.

## 1. Install from the GitHub tag

ElfUI is not published to npm. Install a tagged release straight from GitHub and pin the tag:

::install-command{extra="tailwindcss @tailwindcss/vite"}
::

```bash
bun add -d typescript@5
```

::callout{type="info" title="Why TypeScript?"}
The Vue compiler uses the `typescript` package to resolve the Reka UI prop types inside ElfUI's single-file component sources. Install **TypeScript 5 or 6**: TypeScript 7 is the native port and no longer exposes the JavaScript API the Vue compiler needs, so builds fail with "No fs option provided to `compileScript`".
::

## 2. Configure Nuxt

```ts [nuxt.config.ts]
import tailwindcss from '@tailwindcss/vite'

export default defineNuxtConfig({
  modules: ['@elf/ui/nuxt'],
  css: ['~/assets/css/main.css'],
  elf: { theme: 'novatron' }, // 'elf' | 'novatron'
  vite: { plugins: [tailwindcss()] },
})
```

The module registers every component with the `Elf` prefix, adds the token CSS of the selected theme and sets `data-theme` on `<html>`. To bundle more themes for runtime switching, list them: `elf: { theme: 'novatron', themes: ['elf'] }`.

## 3. Add the Tailwind v4 entry

```css [app/assets/css/main.css]
@import 'tailwindcss';
@import '@elf/ui/styles.css';
```

`@elf/ui/styles.css` maps ElfUI tokens to Tailwind colors (`bg-primary`, `text-muted-foreground`, ...) and radii, and tells Tailwind to scan the ElfUI component sources. Import it **after** Tailwind.

## 4. Use a component

```vue [app/pages/index.vue]
<template>
  <ElfCard>
    <ElfCardHeader>
      <ElfCardTitle>Hello ElfUI</ElfCardTitle>
      <ElfCardDescription>Components are auto-imported.</ElfCardDescription>
    </ElfCardHeader>
    <ElfCardContent>
      <ElfButton>Save</ElfButton>
    </ElfCardContent>
  </ElfCard>
</template>
```

## Module options

| Option | Type | Default | Description |
| :-- | :-- | :-- | :-- |
| `theme` | `'elf' \| 'novatron'` | `'elf'` | Theme applied through `data-theme` on `<html>`. |
| `themes` | `ElfTheme[]` | selected theme only | Extra theme token files to bundle. |
| `prefix` | `string` | `'Elf'` | Component name prefix. |

## Pinning and upgrading

Always pin a tag. To upgrade, remove and add again so the lockfile picks up the new commit:

```bash
bun remove @elf/ui
bun add github:xouyi/elfUI#vX.Y.Z
```

## Try the example

The repository contains a complete Nuxt 4 app that installs ElfUI from a tag exactly as above: [`examples/nuxt-demo`](https://github.com/xouyi/elfUI/tree/main/examples/nuxt-demo). Its build runs in CI on every change, so these steps are tested against a real install.
