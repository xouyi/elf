---
title: Registry
description: Copy ElfUI components into your project with the elfui CLI (or shadcn-vue) and fork them freely.
---

Prefer to own the code? The registry serves every component as plain source files. The [`elfui` CLI](/docs/getting-started/cli) copies them into your project and rewrites imports to your own aliases (`@/lib/utils`, `@/components/ui/*`), so you can fork them freely.

## Add components

```bash
bunx {{pkg}} add button dialog
```

Dependencies such as `utils` (the `cn()` helper) and sibling components are added automatically through `registryDependencies`, and missing npm dependencies are installed with Bun. Files that already exist are never overwritten unless you pass `--overwrite`.

## Alternative: shadcn-vue

The same files are a standard [shadcn-vue](https://www.shadcn-vue.com) registry, so its CLI works too:

```bash
bunx shadcn-vue@latest add {{registry}}/button.json
```

Or register the namespace in `components.json` and use short names:

```json [components.json]
{
  "registries": {
    "@elf": "{{registry}}/{name}.json"
  }
}
```

```bash
bunx shadcn-vue@latest add @elf/button @elf/dialog @elf/elf-theme
```

`@elf` is only the shadcn-vue namespace for this registry. The npm package is `{{pkg}}`.

## Available items

| Item | Description |
| :-- | :-- |
| `utils` | `cn()` helper (clsx and tailwind-merge) |
| `button`, `input`, `badge`, `card`, `dialog`, `tabs`, ... | Components. Run `bunx {{pkg}} list` for all of them. |
| `elf-theme` | Tailwind v4 token mapping and the `elf`, `nova` and `elfwood` theme files |

The full index is served at [`/r/registry.json`]({{registry}}/registry.json).

## Fallback host

If GitHub Pages is unavailable, the same files are served from the repository:

```text
{{registry-raw}}/{name}.json
```

Use it with the CLI: `bunx {{pkg}} add button --registry {{registry-raw}}/`. Items fetched from the fallback still list the Pages URL in their `registryDependencies`.

## Package or registry?

| | Package (`{{pkg}}`) | Registry |
| :-- | :-- | :-- |
| Updates | `bun update {{pkg}}` | Re-run `add --overwrite` and merge (`elfui diff` shows the changes) |
| Customization | Props, classes, tokens | Edit the source |
| Best for | Following the design system | Heavily customized apps |
