---
title: Install from GitHub
description: Advanced. Install an unreleased ElfUI commit or tag straight from GitHub instead of npm.
---

Use the npm package unless you need something that is not released yet. Everything on the Installation pages applies; only the install command differs.

::callout{type="warning" title="Advanced"}
A GitHub install builds nothing for you: the CLI binary (`dist/cli.mjs`) is only produced when the package is packed for npm, so `bunx elfui` is not available from a GitHub dependency. Run the CLI from npm (`bunx {{pkg}}@latest`) and install the package from GitHub.
::

## Pin a tag

```bash
bun add github:{{repo-slug}}#v{{version}} tailwindcss @tailwindcss/vite
bun add -d typescript@5
```

Tags are the same versions that go to npm. The package name in `package.json` is still `{{pkg}}`, so imports do not change.

## Try an unreleased commit

```bash
bun add github:{{repo-slug}}#<commit-sha>
```

## Upgrade

Remove and add again so the lockfile records the new commit:

```bash
bun remove {{pkg}}
bun add github:{{repo-slug}}#vX.Y.Z
```

Moving back to npm is `bun remove {{pkg}} && bun add {{pkg}}`.
