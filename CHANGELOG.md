# Changelog

## Unreleased

- Make theme switching a one-line setup. The Nuxt module has a new `persist` option (`'cookie'` by default, `'localStorage'` or `false`); its plugin reads the cookie on the server so `<html data-theme>` is correct in the first HTML (unknown cookie values are ignored), and a zero-argument `useElfTheme()` uses the module's `theme`/`themes`/`persist` automatically. In plain Vue, the new `createElfTheme({ themes, defaultTheme, persist })` plugin provides the same defaults. `useElfTheme()` gains `toggle()` (flips two themes, cycles more). Existing options still work and override the shared defaults. The module also injects the boot script that applies the stored theme before first paint. The `useElfTheme` docs page now starts with a Quick start for Nuxt and Vite.
- Add `ElfThemeSwitcher`, a ready-made theme control: `variant` `select` (default), `buttons` (a segmented radio group with arrow-key selection) or `toggle` (one icon button that cycles), `label` and `labels` props, a `themes` subset, a swatch per theme, and support for custom themes. It uses `useElfTheme()`, so it needs no `v-model`. Also added to the registry (with `use-elf-theme` and `elf-themes` lib items) and `llms.txt`.
- Add `ElfBreadcrumb`, `ElfBreadcrumbList`, `ElfBreadcrumbItem`, `ElfBreadcrumbLink` (`asChild` for router links), `ElfBreadcrumbPage`, `ElfBreadcrumbSeparator` and `ElfBreadcrumbEllipsis`, composed from native elements: a labelled `nav` with an ordered list, `aria-current="page"` on the last item, aria-hidden separators (any icon through the slot, mirrored in RTL) and an ellipsis that collapses long trails when placed inside an `ElfDropdownMenuTrigger`.

- Add `ElfPagination`, `ElfPaginationContent`, `ElfPaginationItem`, `ElfPaginationEllipsis`, `ElfPaginationFirst`, `ElfPaginationPrev`, `ElfPaginationNext`, `ElfPaginationLast` and `ElfSimplePagination`, built on the Reka UI Pagination primitive: `v-model:page`, `total`, `itemsPerPage`, `siblingCount` (default 1) and `showEdges` (default true), a labelled `nav` with a list of native buttons, `aria-current="page"`, disabled ends, a `disabled` state, and a previous/next bar with a translatable status for simple lists.
- Add `ElfToggle`, `ElfToggleGroup` and `ElfToggleGroupItem` (`toggleVariants`), built on the Reka UI Toggle and ToggleGroup primitives: `variant` `default` or `outline`, `size` `sm`, `default` or `lg`, `v-model`, group `type` `single` or `multiple`, a `joined` segmented layout, per-item overrides, roving focus with arrow keys, Home and End. A single toggle is a button with `aria-pressed`; a single group is a radiogroup. Replaces filter chips and sort selectors.
- Add `ElfAspectRatio`, built on the Reka UI AspectRatio primitive: a fixed `ratio` frame that fills its parent's width, clips and rounds its content, and crops an `img` or `video` child to cover.
- Add `ElfTable` with `ElfTableCaption`, `ElfTableHeader`, `ElfTableBody`, `ElfTableFooter`, `ElfTableRow`, `ElfTableHead` and `ElfTableCell`, on a native table: a required `caption` (optionally `captionHidden`), `density` (`compact`, `default`, `comfortable`), `stickyHeader`, `stackOnMobile` (rows become `label: value` cards below `sm`, with ARIA table roles so the semantics survive), a scroll container that becomes a focusable named region only while it overflows, `sort` on `ElfTableHead` for `aria-sort` (the base for the later data table) and `selected` on `ElfTableRow`.
- Add `ElfEmpty` with `ElfEmptyHeader`, `ElfEmptyMedia` (`variant` `default` or `icon`, `emptyMediaVariants`), `ElfEmptyTitle` (renders an `h3`, configurable with `as`), `ElfEmptyDescription` and `ElfEmptyContent`: an empty state for lists, tables and searches with no results.
- Add `ElfStatCard` and `ElfStatCardLink` (`statCardVariants`): a KPI tile with `label`, `value`, `hint`, `trend` (`trendDirection`, `trendLabel`), `tone` (`default`, `success`, `warning`, `destructive`) and a `loading` skeleton state with `aria-busy`; `ElfStatCardLink` (`as`, `asChild`) stretches one link over the whole card.
- Add `ElfNavigationMenu` with `ElfNavigationMenuList`, `ElfNavigationMenuItem`, `ElfNavigationMenuTrigger`, `ElfNavigationMenuContent`, `ElfNavigationMenuLink` (`variant` `item` or `trigger`, `active`), `ElfNavigationMenuViewport` and `ElfNavigationMenuIndicator`, built on the Reka UI NavigationMenu primitive: a `nav` landmark following the disclosure navigation pattern, flyout panels that share one animated viewport (`viewport` prop, off to place each panel under its trigger), hover and click open, Escape returns focus to the trigger, 40px touch targets on small screens. Exports `navigationMenuTriggerStyle` and `navigationMenuItemLinkClass` for router links.
- Add `ElfMenubar` with `ElfMenubarMenu`, `ElfMenubarTrigger`, `ElfMenubarContent` and the same item parts as `ElfDropdownMenu` (`Item`, `CheckboxItem`, `RadioGroup`, `RadioItem`, `Label`, `Group`, `Separator`, `Shortcut`, `Sub`, `SubTrigger`, `SubContent`), built on the Reka UI Menubar primitive: a `menubar` with one tab stop, arrow-key movement along the bar (wrapping by default), ArrowLeft and ArrowRight to switch open menus, hover to switch while a menu is open, and the shared menu styles of the dropdown menu (so it depends on it in the registry).
- Add `ElfSidebar`, composed from `ElfSheet`, `ElfTooltip`, `ElfSeparator` and `ElfScrollArea` (and `ElfCollapsible` for collapsible groups): `ElfSidebarProvider` (`v-model:open`, `defaultOpen`, Ctrl/Cmd+B `shortcut`, optional `storageKey` persistence), `ElfSidebar` (`side`, `variant` sidebar, floating or inset, `collapsible` offcanvas, icon or none), `ElfSidebarHeader`, `Content`, `Footer`, `Separator`, `Group`, `GroupLabel`, `GroupContent`, `Menu`, `MenuItem`, `MenuButton` (`isActive`, `tooltip` shown in the icon rail, `as-child` for links), `MenuBadge`, `MenuSub`, `Trigger`, `Rail` and `Inset`, plus `useSidebar()` and `sidebarMenuButtonVariants`. Below 768px it becomes an off-canvas sheet with 40px touch rows that closes when a link is chosen; width and slide animations stop under reduced motion.
- Add `ElfStepper`, `ElfStepperItem`, `ElfStepperTrigger`, `ElfStepperIndicator`, `ElfStepperTitle`, `ElfStepperDescription` and `ElfStepperSeparator`, built on the Reka UI Stepper primitive: 1-based `v-model`, `orientation` (`horizontal` | `vertical`), `linear` (default) or free navigation, disabled and completed steps, a check icon for finished steps, a separator that fills with the primary colour, arrow-key navigation, a polite "Step n of m" announcement and slot props (`nextStep`, `prevStep`, `goToStep`, `hasNext`, `hasPrev`) for Back and Next buttons.

## 0.4.0

- **Breaking: the `novatron` theme is now `nova`.** `data-theme="novatron"` becomes `data-theme="nova"`, the file `@xouyi/elfui/themes/novatron.css` becomes `@xouyi/elfui/themes/nova.css`, the Nuxt option `elfui: { theme: 'novatron' }` becomes `theme: 'nova'` (also in `themes: [...]`), `elfui init --theme novatron` becomes `--theme nova`, and `useElfTheme` values stored as `novatron` (cookie or localStorage) must be migrated to `nova`. No compatibility alias. The tokens are unchanged. To migrate: search your project for `novatron` in HTML, CSS imports, `nuxt.config.ts` and stored theme values, and replace it with `nova`.
- Add the `elfwood` theme, the first light theme: white and near-white surfaces, deep forest-green primary (`#15803d`), 0.5rem radius, `color-scheme: light`. Available as `data-theme="elfwood"`, `@xouyi/elfui/themes/elfwood.css`, the Nuxt `theme`/`themes` options, `elfui init --theme elfwood`, `elfThemes` and the docs switcher (with a light Shiki theme). Every example passes axe and every token pair passes `bun run contrast` in it.
- Add the `--elf-success-text` and `--elf-warning-text` tokens and the `text-success-text` / `text-warning-text` utilities: readable status text and icons on `background`, `card` and `popover` (4.5:1, checked by `bun run contrast`). `ElfAlert` titles and icons use them. Custom themes must define both (copy `success` and `warning` for a dark theme).
- Add the `glow` prop to `ElfButton` (and the `glow` variant of `buttonVariants`): a soft glow in the colour of the variant, stronger on hover and keyboard focus, no layout change, static under `prefers-reduced-motion` and removed in `forced-colors`. It is driven by the new `--elf-glow` theme token, a percentage used by `color-mix` (elf `40%`, nova `45%`, elfwood `22%`); custom themes may omit it (a 40% default applies).
- Add `ElfGradientText`, built on `Primitive` (`as`, `asChild`, default `span`): `variant` presets `brand` (theme primary into foreground), `aurora`, `sunset` and `forest`, custom `from`, `via` and `to` colours, `direction`, and an `animate` shimmer that is static under `prefers-reduced-motion`. The text stays real and selectable, `forced-colors` falls back to `CanvasText`, and a unit test checks every preset stop against every theme background (4.5:1). Exports `gradientTextPresets` and `gradientTextDirections`.
- Add `ElfTooltip`, `ElfTooltipTrigger`, `ElfTooltipContent` and `ElfTooltipProvider`, built on the Reka UI Tooltip primitive: opens on hover and keyboard focus, closes on Escape, hoverable content, a shared open delay through the provider (400 ms by default), `side`/`align`, `v-model:open`, and a standalone mode that creates its own provider.
- Add `ElfPopover`, `ElfPopoverTrigger`, `ElfPopoverAnchor`, `ElfPopoverContent` and `ElfPopoverClose`, built on the Reka UI Popover primitive: anchored interactive panel, `v-model:open`, `side`/`align`, optional `modal` focus trap, focus moves in and returns to the trigger, Escape and outside click close, never exceeds the viewport.
- Add `ElfHoverCard`, `ElfHoverCardTrigger` and `ElfHoverCardContent`, built on the Reka UI HoverCard primitive: link preview that opens on hover and keyboard focus with configurable `openDelay` and `closeDelay`, Escape closes, `side`/`align`, `v-model:open`; shares the panel styles of `ElfPopover` (`popoverPanelClass`).
- Add `ElfDropdownMenu` with `ElfDropdownMenuTrigger`, `ElfDropdownMenuContent`, `ElfDropdownMenuItem` (`variant` default or destructive, `inset`), `ElfDropdownMenuCheckboxItem`, `ElfDropdownMenuRadioGroup`, `ElfDropdownMenuRadioItem`, `ElfDropdownMenuLabel`, `ElfDropdownMenuGroup`, `ElfDropdownMenuSeparator`, `ElfDropdownMenuShortcut` and `ElfDropdownMenuSub`, `ElfDropdownMenuSubTrigger`, `ElfDropdownMenuSubContent`, built on the Reka UI DropdownMenu primitive: roving focus, typeahead, sub menus, 40px touch rows on small screens, and shortcut hints for `ElfKbd`. The shared class helpers (`menuContentClass`, `menuItemVariants`, `menuLabelClass`, `menuSeparatorClass`, `menuShortcutClass`) are exported.
- Add `ElfContextMenu` with `ElfContextMenuTrigger`, `ElfContextMenuContent` and the same item parts as `ElfDropdownMenu` (`Item`, `CheckboxItem`, `RadioGroup`, `RadioItem`, `Label`, `Group`, `Separator`, `Shortcut`, `Sub`, `SubTrigger`, `SubContent`), built on the Reka UI ContextMenu primitive: opens on right-click, long-press, Shift+F10 and the ContextMenu key, shares its styles with the dropdown menu.
- Add `ElfScrollArea` and `ElfScrollBar`, built on the Reka UI ScrollArea primitive: native scrolling with styled scrollbars, `type` (`hover`, `scroll`, `auto`, `always`), `orientation` (`vertical`, `horizontal`, `both`), `scrollHideDelay`, a keyboard focusable viewport with a focus ring, and a `label` that names it as a region.
- Add `ElfAlertDialog` with `ElfAlertDialogTrigger`, `ElfAlertDialogContent`, `ElfAlertDialogHeader`, `ElfAlertDialogTitle`, `ElfAlertDialogDescription`, `ElfAlertDialogFooter`, `ElfAlertDialogCancel` and `ElfAlertDialogAction`, built on the Reka UI AlertDialog primitive: role `alertdialog`, initial focus on Cancel, never dismissed by an outside click, a destructive action variant, and the same surface as `ElfDialog` (its overlay and content classes are now shared through `dialogOverlayClass` and `dialogContentClass`).
- Add `ElfSheet` with `ElfSheetTrigger`, `ElfSheetContent`, `ElfSheetHeader`, `ElfSheetTitle`, `ElfSheetDescription`, `ElfSheetFooter` and `ElfSheetClose` (`sheetVariants`), built on the Reka UI Dialog primitive: `side` (`top` | `right` | `bottom` | `left`), `size` (`sm` | `default` | `lg` | `full`), a mobile-friendly bottom sheet with safe-area padding, a 40px close button on small screens, slide animations with a reduced-motion fallback. Adds the `elf-slide-*` keyframes to `styles.css`.
- Add `ElfToaster` and `useToast()` / `toast` (`toastVariants`), built on the Reka UI Toast viewport and manager: `toast(message, { description, variant, duration, action })`, `toast.success`, `toast.warning`, `toast.error`, `toast.promise`, `toast.update` and `toast.dismiss`; `position`, `limit`, `duration`, `hotkey` (F8) props, swipe to dismiss, pause on hover and focus, persistent polite (`role=status`) and assertive (`role=alert`) live regions, safe-area aware layout and a module-singleton queue that is a no-op on the server. The Nuxt module auto-imports `useToast`.
- Add `ElfCollapsible`, `ElfCollapsibleTrigger` and `ElfCollapsibleContent`, built on the Reka UI Collapsible primitive: `v-model:open`, `disabled`, a height animation that settles at the natural height, and a reduced-motion fallback. Adds the `elf-collapsible-*` keyframes to `styles.css` and the shared `collapsibleContentClass`.
- Add `ElfAccordion`, `ElfAccordionItem`, `ElfAccordionTrigger` and `ElfAccordionContent`, built on the Reka UI Accordion primitive: `type` `single` (with `collapsible`) or `multiple`, `v-model`, disabled items, arrow-key, Home and End navigation, an animated height shared with `ElfCollapsible`, a rotating chevron (`icon` slot) and reduced-motion fallbacks.
- Add the optional `--elf-overlay` theme token: the scrim colour behind `ElfDialog`, `ElfAlertDialog` and `ElfSheet` (default `rgb(0 0 0 / 0.8)`; `elfwood` uses a lighter green-black). The docs set `color-scheme` to `light dark` so light-theme visitors see no dark flash.
- `ElfToaster` status icons use `text-success-text` and `text-warning-text`, so they stay readable on the light `elfwood` surfaces.

- Add the `useElfTheme()` composable (`theme`, `themes`, `setTheme`, `cycle`) and `elfThemeBootScript()`: reads and sets `data-theme` on `<html>`, SSR-safe (per-app state, no `document` access on the server), typed theme names with support for custom themes, optional persistence in a cookie or localStorage, auto-imported by the Nuxt module. `elfThemes`, `ElfTheme` and the new `isElfTheme()` now live in `src/lib/themes.ts` and are still exported from the package root.
- Add the `--elf-destructive-text` token and the `text-destructive-text` utility: readable error text on `background`, `card` and `popover` (7.2:1 or better in both themes, checked by `bun run contrast`). `ElfFieldError`, the required marker of `ElfFieldLabel`, the Input, Textarea and Label examples and `ElfAlert` use it instead of mixing `destructive` with white. Custom themes must define `--elf-destructive-text`.
- Add `ElfAvatar`, `ElfAvatarImage`, `ElfAvatarFallback` and `ElfAvatarGroup` (`avatarVariants`), built on the Reka UI Avatar primitive: image with fallback, initials from `name`, `size` (`sm` | `default` | `lg` | `xl`), a `label` that exposes the avatar as one named image, and an overlapping group.
- Add `ElfProgress`, built on the Reka UI Progress primitive: determinate (`v-model`, `max`) and indeterminate (`null`) bars, `size`, `label`, `aria-labelledby` wiring, `getValueText`, `indicatorClass`, and a reduced-motion fallback. Adds the `elf-progress-indeterminate` keyframes to `styles.css`.
- Add `ElfAlert`, `ElfAlertTitle` and `ElfAlertDescription` (`alertVariants`): `default`, `destructive`, `success` and `warning` variants with per-variant icons, an `icon` slot, `showIcon`, and `role` handling (`alert` for destructive, `status` otherwise, `none` to drop the role).
- Add `ElfSelect` with `ElfSelectTrigger`, `ElfSelectValue`, `ElfSelectContent`, `ElfSelectItem`, `ElfSelectGroup`, `ElfSelectLabel`, `ElfSelectSeparator`, `ElfSelectScrollUpButton` and `ElfSelectScrollDownButton`, built on the Reka UI Select primitive: popper positioning, typeahead, `size`, `invalid`, 16px text on small screens, and `ElfField` wiring through `ElfFieldControl` around the trigger.
- Add `ElfSwitch`, built on the Reka UI Switch primitive: `v-model`, `size` (`default` | `sm`, exported `switchVariants`), `disabled`, a `thumb` slot, Space and Enter toggling, and `ElfField` wiring.
- Add `ElfRadioGroup` and `ElfRadioGroupItem`, built on the Reka UI RadioGroup primitive: `v-model`, `orientation`, `disabled`, `required`, `invalid`, roving arrow-key selection, and in `ElfField` the group is named by the field label and gets the described, invalid and required wiring.
- Add `ElfCheckbox`, built on the Reka UI Checkbox primitive: `v-model` (`boolean | 'indeterminate'`), `invalid`, `disabled`, `required`, a custom indicator slot, and automatic id, `aria-describedby`, `aria-invalid` and required wiring inside `ElfField`.
- Theme: the `elf` theme now uses pure black, neutral (zero-chroma) surfaces instead of purple-tinted near-black: background `#000000`, card `#0a0a0a`, popover `#0f0f0f`, muted `#171717`, secondary `#1c1c1c`, border `#262626`, input `#6b6b6b`. Violet stays the brand accent (`primary`, `ring`) and `accent` is a subtle violet for hover and selected states. All pairs still pass WCAG AA (`bun run contrast`). Visual baselines of the `elf` theme change.

## 0.3.0

- **Breaking rename: `@elf/ui` is now `@xouyi/elfui`.** The package is published on npm as `@xouyi/elfui` (the unscoped `elfui` name was rejected by npm as too similar to the existing `elf-ui`). Imports become `from '@xouyi/elfui'`, `@xouyi/elfui/nuxt`, `@xouyi/elfui/styles.css`, `@xouyi/elfui/themes/*.css` and `@xouyi/elfui/lib/utils`. The installed CLI binary is still `elfui`, the Nuxt module option key becomes `elfui:` (was `elf:`) and the `Elf` component prefix is unchanged. No compatibility shim: `@elf/ui` was never published to npm. Upgrade from a GitHub install: `bun remove @elf/ui && bun add @xouyi/elfui`, then rename the imports and the `elf:` config key.
- Add the `elfui` CLI (`bunx @xouyi/elfui@latest init | add | list | diff`; the installed binary is `elfui`): sets up Nuxt or Vite + Vue projects idempotently and copies registry components with import rewriting, never overwriting without `--overwrite`. Zero runtime dependencies, built to `dist/cli.mjs`; unit and end-to-end tests run in `bun run check`.
- Release: pushing a `vX.Y.Z` tag publishes to npm with Trusted Publishing (OIDC, provenance, `-beta.N` goes to the `next` tag) and creates the GitHub Release from this changelog.
- Docs: Installation pages rewritten around `bun add @xouyi/elfui` and `bunx @xouyi/elfui@latest init`; new CLI page; GitHub installs moved to "Install from GitHub".
- npm-ready package: `files` whitelist, `publishConfig` (public, provenance), `bin`, `keywords`, `homepage`, `bugs`, `engines` and peer dependencies (`vue`, `tailwindcss`, `@tailwindcss/vite`, `typescript`, optional `nuxt`).
- Add `ElfField` with `ElfFieldControl`, `ElfFieldLabel`, `ElfFieldDescription` and `ElfFieldError`: label, control, description and error wired through `id`, `for`, `aria-describedby`, `aria-invalid` and `aria-required`, plus `useFieldContext()`; works with `ElfInput` and `ElfTextarea`.
- Add `ElfTextarea`: native textarea with `v-model`, `autoResize`, `invalid`, `rows` and `maxlength`, sharing the `ElfInput` styles.
- Add `ElfSkeleton`: a decorative placeholder block (`aria-hidden`, reduced-motion aware).
- Add `ElfSpinner`: an SVG busy indicator with `size` and an announced `label` (`role="status"`), reduced-motion aware.
- Add `ElfKbd` and `ElfKbdGroup`, composed from the native `kbd` element.
- Add `ElfSeparator`, built on the Reka UI Separator primitive (`orientation`, `decorative`, default decorative).
- Add `ElfLabel`, built on the Reka UI Label primitive (`for`, `as`, `asChild`), with `peer-disabled` and `group` disabled styling.
- Add `ElfVisuallyHidden`, built on the Reka UI VisuallyHidden primitive (`as`, `asChild`, `feature`).
- Docs: Storybook is gone. The documentation is a Nuxt 4 + Nuxt Content site (`apps/docs`) built with ElfUI itself, with live previews and copyable source for every example, API tables generated from the component sources (`vue-component-meta`), a live theme token and contrast table, Cmd/Ctrl+K search, and a page per component. Published at https://xouyi.github.io/elfUI/.
- Examples: component stories became `src/components/<name>/examples/*.vue`, the single source for docs previews and tests.
- The repository is now `xouyi/elfUI`. Registry URLs are `https://xouyi.github.io/elfUI/r/`.
- Removed `bun run storybook`, `bun run build-storybook` and the Storybook-based tests; `bun run check` builds the docs site instead (`bun run docs:build`).
- Tests: Vitest browser project (real Chromium) mounts every example in both themes and requires zero `axe-core` violations, plus interaction tests for Dialog focus and Escape handling, Tabs keyboard navigation, Button `as-child` and Input `v-model`. `bun run test:browser`.
- Visual regression: Playwright screenshots every example in isolation (`/__examples/<component>/<example>` on the docs site) in both themes at 1280 and 360 px; baselines are created only by the Visual baselines workflow in the Playwright image. New docs page "Testing".
- Fix: the Input "Invalid" example error text now meets 4.5:1 contrast in both themes.
